求余 %

求余结果的正负只由第二个数字（除数）决定，和第一个数字无关：只有第二个数字是负数时，结果才是负数（被除数 = 除数 * 商 + 余数）。% 两边都是整数时结果是整数，只要有一个是小数，结果就是小数。

print(15 % 6, -15 % 6, 15 % -6, -15 % -6)
print(7.7 % 2.2, -7.7 % 2.2, 7.7 % -2.2, -7.7 % -2.2)
print(23.5 % 6, 23 % 6.5, 23.5 % -6, -23 % 6.5, -23 % -6.5)

开方

连续赋值与交换

Python 中的赋值表达式也有值，就是被赋的那个值（左侧变量的值）。把赋值的结果再赋给另一个变量，就构成连续赋值：

a = b = c = 100       # 三个变量指向同一个值
x, y = 1, 2
x, y = y, x           # 交换两个变量的值
print(a, b, c, x, y)

100 100 100 2 1

Warning

对可变对象连续赋值时，几个变量引用的是同一个对象：A = B = [1, 2] 后 B.append(3)，A 也会变成 [1, 2, 3]。

海象运算符

:= 在表达式内部给变量赋值，同时把这个值作为表达式的结果：

num1 = 20
print((num2 := 3 ** 2) > num1)   # num2 = 9，再与 20 比较
print(num2)

False
9

Tip

海象运算符常用于 if、while 条件里避免重复计算，例如 分支结构 中先取随机年龄再判断。独立的赋值语句仍然用 =。

比较运算符

比较运算符也称关系运算符，对常量、变量或表达式的结果进行大小比较，成立返回 True，否则返回 False。

运算符说明实例
==相等，比较两者的值a == b

num2 = 20
print(num1 == num2)   # False
print(num1 != num2)   # True
print(num1 > num2)    # False
print(num1 < num2)    # True
print(num1 >= num2)   # False
print(num1 <= num2)   # True

# 不能自动转换的类型之间不能比较大小
# print(num1 > 'abc')   # TypeError: '>' not supported between instances of 'int' and 'str'

# 字符串比较大小：从最左边开始逐个比较对应位置字符的编码值

print('15' > '6')   # False，先比较 '1' 和 '6'
print('abc' < 'abd', 'a' < 'B')   # True False（'a' 是 97，'B' 是 66）

比较运算符可以连着写，1 < 2 < 3 相当于 1 < 2 and 2 < 3，结果为 True；1 < 3 < 2 为 False。

短路与返回值

and 和 or 不一定会计算右边的表达式，只算左边就能得出结果时，右边根本不执行（短路）。它们把其中一个表达式的值作为最终结果，而不是把 True 或 False 作为结果。

  • and：两边都真才为真，只要有一个假就是假。左边为假时，不用再算右边，结果就是左边的值；左边为真时，结果不能确定，继续计算右边，并以右边的值为结果。
  • or：两边都假才为假，只要有一个真就是真。左边为真时，不用再算右边，结果就是左边的值；左边为假时，继续计算右边，并以右边的值为结果。
name = ""
print(name or "匿名")    # 常用来提供默认值

匿名

条件表达式（三目）

Python 没有传统的 ? : 条件运算符，但提供了更清晰的 if-else 表达式。有人把它称为三目运算符或三元运算符。格式如下：

exp1 if condition else exp2

condition 是判断条件，exp1 和 exp2 是两个表达式。condition 成立（结果为真）时，计算 exp1 并作为整个表达式的结果；不成立时，计算 exp2 并作为结果。

a = 10
b = 9
max_value = a if a > b else b
print(max_value)

age = 20
print("成年" if age >= 18 else "未成年")

10
成年

Tip

变量名不要叫 max，它会覆盖内置函数 max()，示例里用 max_value。

成员运算符

in 用来检查某个元素是否存在于序列、集合等可迭代对象中。

运算符说明实例
in在指定的序列、集合等容器中找到值返回 True，否则返回 Falsea in ['a', 'b', 'c']
not in在指定的容器中没有找到值返回 True，否则返回 Falsea not in ['a', 'b', 'c']
a = "hello"
print('h' in a)       # True
print('p' in a)       # False
print('p' not in a)   # True

a = [1, 2, 3, 4, 5]   # 列表
print(2 in a)         # True
print(6 in a)         # False
print(6 not in a)     # True

字符串的 in 判断子串（'ell' in 'hello' 为 True）；字典的 in 只检查键，不检查值。更多容器的 in 见 容器通用操作。

== 与 is

初学 Python 的人常把 is 和 == 混为一谈，其实它们有本质区别：

比较方式比较内容示例
==对象的值（内容）a == b
is对象的身份（内存地址），判断两个标识符是否引用同一个对象，类似 id(a) == id(b)a is b

is not 判断两个标识符是否引用不同的对象，类似 id(a) != id(b)。

a = "123"
b = str(123)
print(a is b)          # False，地址不同
print(id(a) == id(b))  # False，地址不同
print(a == b)          # True，内容相同

再看一个例子，time.gmtime() 用来获取当前时间，精确到秒：

import time

t1 = time.gmtime()   # gmtime() 用来获取当前时间
t2 = time.gmtime()

print(t1 == t2)
print(t1 is t2)

True
False

程序运行很快，所以 t1 和 t2 的时间一样（若恰好跨过整秒则可能不同），== 判断值相等，返回 True。但每次调用 gmtime() 都返回一个新对象，t1 和 t2 是两个不同的对象，所以 t1 is t2 返回 False。这就像两个长得一样的双胞胎，是两个人；两个名字使用了同一个身体，才是同一个人。

Tip

is 最合适的用法是和单例比较：x is None、x is not None。对数字、字符串用 is 判断大小是否相等是错误用法，Python 3.8+ 对 x is 1 这样的写法还会给出 SyntaxWarning。小整数池导致的"碰巧相等"见 整数 int。

进制转换

  • 十进制转 N 进制：将该数不断除以 N，直到商为 0，然后把每步得到的余数倒过来读，就是对应的 N 进制数（N 取 2、8、16）。
  • N 进制转十进制：从最低位开始，把每一位上的数乘以 N 的（位数 - 1）次方，然后求和（N 取 2、8、16）。
  • 二进制转十六进制：从低位开始，每 4 位一组（2 的 4 次方等于 16）；不是 4 的倍数时，在最左边补零；每组转成对应的十六进制数。
  • 二进制转八进制：从低位开始，每 3 位一组，每组转成对应的八进制数。
  • 十六进制转二进制：每 1 位转成对应的 4 位二进制数。
  • 八进制转二进制：每 1 位转成对应的 3 位二进制数。

Python 提供了内置函数完成转换：

print(bin(25), oct(25), hex(25))
print(int("11001", 2), int("31", 8), int("19", 16))
print(format(25, "b"), format(25, "08b"), format(255, "X"), format(255, "#x"))

符号位与原码、反码、补码

一个数在计算机中的二进制表示形式叫做这个数的机器数。机器数是带符号的，最高位存放符号，正数为 0，负数为 1。

  • 正数：原码、反码、补码一致。
  • 负数：原码、反码、补码各不相同。
  • 位运算以补码形式进行计算。

以 1 个字节（8 位）为例：

正数 25负数 -25
原码符号位加上真值的绝对值：00011001符号位加上真值的绝对值：10011001
反码等于原码：00011001原码符号位不变，其余位取反：11100110
补码等于原码：00011001反码的基础上加 1：11100111

Python 的整数没有固定位数，不存在真正溢出，所以 bin(-25) 得到 -0b11001（负号加绝对值）。想看到 8 位补码，可以与 0xFF 做按位与：

print(bin(-25 & 0xFF))     # 补码
print(bin(~25 & 0xFF))     # 反码

0b11100111
0b11100110

取反 ~

~ 是单目运算符（只有一个操作数），右结合，作用是对二进制位取反：~1 为 0，~0 为 1，类似逻辑运算中的"非"。对整数来说，~x 等于 -x - 1。~9 的运算如下：

 ~ 0000 0000 -- 0000 0000 -- 0000 0000 -- 0000 1001   （9 在内存中的存储）
-----------------------------------------------------------------------
   1111 1111 -- 1111 1111 -- 1111 1111 -- 1111 0110   （-10 在内存中的存储）

左移 «

<< 把操作数的各个二进制位全部左移若干位，高位丢弃，低位补 0。9 << 3 的运算如下：

 << 0000 0000 -- 0000 0000 -- 0000 0000 -- 0000 1001   （9 在内存中的存储）
-----------------------------------------------------------------------
    0000 0000 -- 0000 0000 -- 0000 0000 -- 0100 1000   （72 在内存中的存储）

右移 »

>> 把操作数的各个二进制位全部右移若干位，低位丢弃，高位补 0 或 1：最高位是 0 就补 0，最高位是 1 就补 1（算术右移，符号不变）。9 >> 3 的运算如下：

 >> 0000 0000 -- 0000 0000 -- 0000 0000 -- 0000 1001   （9 在内存中的存储）
-----------------------------------------------------------------------
    0000 0000 -- 0000 0000 -- 0000 0000 -- 0000 0001   （1 在内存中的存储）

a = 17
b = 13

print("有负数异或运算: -12 ^ 17 = ", c ^ a)

print("正数左移运算: 17 << 1 = ", a << 1)
print("正数右移运算: 17 >> 3 = ", a >> 3)
print("负数左移运算: -12 << 2 = ", c << 2)
print("负数右移运算: -12 >> 3 = ", c >> 3)
