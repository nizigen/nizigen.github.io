PYTHON

函数把一段可重复使用的代码封装成一个独立的功能单元：接收输入（参数）、执行逻辑、返回结果。程序里反复出现的代码都值得抽成函数——代码更短更清楚，改一处全局生效，也方便分工和测试。

print()、len()、input() 这些是 Python 自带的内置函数；用 def 自己定义的叫自定义函数。函数必须先定义后使用。

函数的定义与调用

用 def 定义函数：

def 函数名(参数列表):
    函数体
    return [表达式]
  • 以 def 开头，后接函数名和圆括号 ()，行尾是冒号，函数体缩进。
  • 函数名遵循标识符命名规则，一般是动词。命名风格用 ==snake_case==（全小写、下划线分词），详见 04.编码规范。
  • 参数列表是函数需要的数据，多个参数用逗号分隔。函数可以没有参数，但圆括号不能省略。
  • 函数体一般含三部分：文档说明、功能代码、return [表达式]。
  • return 结束函数并把值交给调用方；不带表达式的 return 或没有 return 语句，都相当于返回 None。

定义完不调用不会执行，调用一次执行一次。

def print_hello():
    """
    打印hello world
    """
    print("hello world")

# 先定义，再调用
print_hello()
print("--------")
print_hello()

hello world
--------
hello world

带参数和带返回值的写法：

def print_star(line, column):
    """
    打印指定行数和列数的星号
    """
    for i in range(line):
        for j in range(column):
            print("*", end=" ")
        print()

def add(a, b):
    """
    返回两个数的和
    """
    return a + b

print_star(5, 10)
print("add(1, 2) = ", add(1, 2))
print("add(2, 3) = ", add(2, 3))

* * * * * * * * * *
* * * * * * * * * *
* * * * * * * * * *
* * * * * * * * * *
* * * * * * * * * *
add(1, 2) =  3
add(2, 3) =  5

函数带来的好处：程序更简短清晰；提高开发效率和代码重用性；便于分工协作、集中管理和后期维护。

返回值

按函数体里 return 的写法，返回值分三种情况。

没有 return 语句

函数体没有 return，函数就没有返回值。不接收返回值也能调用，但它确实产生一个 None：

def print_hello():
    """
    打印hello
    """
    print("hello")

print_hello()
print("结果：", print_hello())
result = print_hello()
print("result=", result)

hello
hello
结果： None
hello
result= None

只有 return

return 后面没有值，同样返回 None。这种 return 的实际用途是提前结束函数：

def print_star(line, column):
    """
    打印指定行数和列数的星号
    """
    if line <= 0 or column <= 0:
        return  # 提前结束函数的执行
    for i in range(line):
        for j in range(column):
            print("*", end=" ")
        print()

print_star(3, 5)
print("结果是", print_star(3, 5))

* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
结果是 None

return 值

return 表达式 把值返回给调用方。不用变量接收也不会报错，只是返回值被丢弃——如果函数里没有打印语句，看上去就像没执行：

def add(a, b):
    """
    返回两个数的和
    """
    return a + b

add(1, 2)                    # 返回值被丢弃
print("add(1, 2) = ", add(1, 2))
result = add(1, 2)           # 用变量接收
print("result=", result)

add(1, 2) =  3
result= 3

Note

return 会把一个值交回调用方；需要一次返回多个值时写 return a, b，实际返回的是元组（见 元组）。

参数

形参和实参

  • 定义函数时写的参数叫形式参数，简称形参；调用函数时传进去的参数叫实际参数，简称实参。
  • 定义时形参不占存储空间、没有值，只是占位符。调用时才会在栈区给函数分配空间，再给形参和局部变量分配空间，并让形参引用实参对象。函数执行结束，这块栈空间被释放，形参和局部变量一起消失。

位置参数

实参的顺序和个数必须与形参完全一致：

def print_info(name, age):
    print(f"{name} 的年龄是：{age}")

print_info("张三", 18)

张三 的年龄是：18

默认值参数

含默认值的形参可以不给实参，不传时用默认值。约束是：含默认值的形参必须排在所有不含默认值的形参后面。

def print_info(name, age=18):
    print(f"{name} 的年龄是：{age}")

print_info("张三", 20)  # 正常给 age 赋值
print_info("张三")      # 不传 age，用默认值 18

张三 的年龄是：20
张三 的年龄是：18

Warning

默认值只在函数定义时求值一次，所以不要用可变对象当默认值。def f(x, lst=[]) 里的 lst 会被所有调用共享，追加的内容会累积。

关键字参数

调用时用形参名指定给谁赋值，实参顺序就可以任意：

def print_info(name, age, gender='男'):
    print(f"{name} 的年龄是：{age}，性别是：{gender}")

print_info(age=18, name="张三")
print_info(gender='女', name="张三", age=18)

张三 的年龄是：18，性别是：男
张三 的年龄是：18，性别是：女

强制位置参数或关键字参数：/ 与 *

参数列表里可以放两个分隔符：

  • / 前面的参数只能用位置传参；
  • * 后面的参数只能用关键字传参。
def print_info(name, age, /, gender, hobby, *, city):
    print(f"{name} 的年龄是：{age}，性别是：{gender}，爱好是：{hobby}，城市是：{city}")

print_info("张三", 18, "男", "看电影", city="上海")
print_info("张三", 18, gender="男", hobby="看电影", city="上海")

张三 的年龄是：18，性别是：男，爱好是：看电影，城市是：上海
张三 的年龄是：18，性别是：男，爱好是：看电影，城市是：上海

name、age 在 / 前，写 name="张三" 会 TypeError；city 在 * 后，写 "上海" 作位置实参也会 TypeError。

解包传参

  • 用 * 解包列表或元组：元素按位置依次传给形参，顺序、个数都要对得上。
  • 用 ** 解包字典：字典的 key 必须和形参名一致，相当于一次传一批关键字参数。
def print_info(name, age):
    print(f"{name} 的年龄是：{age}")

print_info(*["张三", 18])
print_info(*("张三", 18))
print_info(**{"name": "张三", "age": 18})

张三 的年龄是：18
张三 的年龄是：18
张三 的年龄是：18

[warning] 集合是无序的，print_info(*{"张三", 18}) 每次运行的元素顺序都可能不同，会随机变成 18 的年龄是：张三。解包只用列表、元组和字典，别用集合。

可变长度参数：*args 与 **kwargs

  • *args：接收任意数量的位置参数，打包成 tuple。
  • **kwargs：接收任意数量的关键字参数，打包成 dict。

约定和限制：

  • 普通参数在前，可变长度参数在后。
  • 一个函数最多一个 *args 和一个 **kwargs。
  • **kwargs 后面不允许再有任何参数。
  • *args 后面可以还有参数，但这些参数必须用关键字传参；要给 *args 后面的参数设默认值，只能定义在 *args 之后。
def print_info(name, *hobby):
    print(f"{name} 的爱好是：{hobby}")

print_info("张三", "跑步", "看电影", "看小说")

# *args 后面的参数必须用关键字传参
def print_info_age(name, *hobby, age):
    print(f"{name} 的爱好是：{hobby}，年龄：{age}")

print_info_age("张三", "跑步", "看电影", "看小说", age=18)

张三 的爱好是：('跑步', '看电影', '看小说')
张三 的爱好是：('跑步', '看电影', '看小说')，年龄：18

def print_info(name, *hobby, **contact_person):
    print(f"{name} 的爱好是：{hobby}，联系人有：{contact_person}")

print_info("张三", "跑步", "看电影", "看小说", mon="12345678901", dad="12345678902")

张三 的爱好是：('跑步', '看电影', '看小说')，联系人有：{'mon': '12345678901', 'dad': '12345678902'}

*args 和 **kwargs 只是习惯叫法，真正起作用的是 * 和 **；叫 *hobby、**contact_person 也一样。

参数传递

变量没有类型

在 Python 里类型属于对象，变量没有类型。下面这段代码里 10 是 int 对象、"helloworld" 是 str 对象，而变量 a 只是先后引用了这两个对象：

a = 10
a = "helloworld"

引用与 id

变量和数据分开存放：数据在内存里有一个位置，变量保存的是这个位置的地址，这种记录地址的关系叫引用。id() 返回对象的内存地址。

给变量重新赋值，本质是换了一个引用对象，相当于撕下便签纸贴到新数据上：

a = 500
print(id(a))
a = 1000
print(id(a))

2684855178608
2684855178704

Note

id 的具体数值每次运行都不同，而且同一个对象在不同运行里地址也不一样。看代码输出时只关心 ==地址有没有变==，不要记具体数字。

可变与不可变类型

  • 不可变（immutable）：数字、字符串、元组。任何"修改"都会产生新对象，即修改引用。
  • 可变（mutable）：列表、集合、字典。有的操作在原对象上直接改、不产生新对象（append、remove、+=、*=），有的操作会产生新对象（=、union、difference）。

不可变类型：

s = "hello"
print("s：", s, ",id(s)：", id(s))
s = s.replace("e", "a")
print("s：", s, ",id(s)：", id(s))   # 地址改变
s += "world"
print("s：", s, ",id(s)：", id(s))   # 地址改变

s： hello ,id(s)： 2684857651712
s： hallo ,id(s)： 2684854875936
s： halloworld ,id(s)： 2684854776560

可变类型：

list_demo = [1, 2]
print("list_demo：", list_demo, ",id(list_demo)：", id(list_demo))
list_demo.append(3)
print("list_demo：", list_demo, ",id(list_demo)：", id(list_demo))   # 地址不变
list_demo += [4, 5]
print("list_demo：", list_demo, ",id(list_demo)：", id(list_demo))   # 地址不变
list_demo = list_demo + [6, 7]
print("list_demo：", list_demo, ",id(list_demo)：", id(list_demo))   # 地址改变

list_demo： [1, 2] ,id(list_demo)： 2684857868736
list_demo： [1, 2, 3] ,id(list_demo)： 2684857868736
list_demo： [1, 2, 3, 4, 5] ,id(list_demo)： 2684857868736
list_demo： [1, 2, 3, 4, 5, 6, 7] ,id(list_demo)： 2684857868928

+= 与 = + 的区别

对可变类型来说，la += [4, 5] 调用 __iadd__，在原对象上扩展，地址不变；la = la + [6, 7] 走 __add__，生成新列表再让变量引用它，地址改变。*= 与 = * 同理：

p = [1, 2]
print("p：", p, ",id(p)：", id(p))
p *= 2
print("p：", p, ",id(p)：", id(p))   # 地址不变

q = [1, 2]
print("q：", q, ",id(q)：", id(q))
q = q * 2
print("q：", q, ",id(q)：", id(q))   # 地址改变

p： [1, 2] ,id(p)： 2684857868736
p： [1, 2, 1, 2] ,id(p)： 2684857868736
q： [1, 2] ,id(q)： 2684857868864
q： [1, 2, 1, 2] ,id(q)： 2684857869056

这个区别在传参时会带来完全不同的结果：函数里写 la += ... 会改到实参，写 la = la + ... 不会。

传参机制

Python 中一切都是对象，严格说没有"值传递"和"引用传递"之分，应该说 ==传不可变对象和传可变对象==。两种类型在函数里的表现像 C++ 的值传递和引用传递，但原理仍是引用，传的是引用对象的首地址：

  • 实参是不可变类型：函数里对形参做的任何"修改"都是让形参指向新对象，与实参对象无关。如果参数是元组等容器或者说复杂对象，元素是可变对象，改变元素值会影响实参
  • 实参是可变类型：只改内容（append、+=）会影响到实参，因为形参和实参指向同一个对象；一旦给形参重新赋一个新对象，就与实参无关了。

不可变实参：

def change_str(s):
    print(f"{s} 的id是：{id(s)}")        # 与 x 地址相同
    s = s.replace('e', 'a')
    print(f"{s} 的id是：{id(s)}")        # 地址改变
    s += "world"
    print(f"{s} 的id是：{id(s)}")        # 地址改变

x = "hello"
print("x=", x, ",id(x)=", id(x))
change_str(x)
print("x=", x, ",id(x)=", id(x))        # 内容和地址都未变

x= hello ,id(x)= 2684857651712
hello 的id是：2684857651712
hallo 的id是：2684854875936
halloworld 的id是：2684855423664
x= hello ,id(x)= 2684857651712

可变实参：

def change_list(la):
    print("la：", la, ",id(la)：", id(la))     # 与 y 内容、地址都相同
    la.append(3)
    print("la：", la, ",id(la)：", id(la))     # 内容改变，地址不变
    la += [4, 5]
    print("la：", la, ",id(la)：", id(la))     # 内容改变，地址不变
    la = la + [6, 7]
    print("la：", la, ",id(la)：", id(la))     # 地址改变，不影响 y

y = [1, 2]
print("y：", y, ",id(y)：", id(y))
change_list(y)
print("y：", y, ",id(y)：", id(y))             # y 内容改变，地址不变

la： [1, 2] ,id(la)： 2684857868864
la： [1, 2, 3] ,id(la)： 2684857868864
la： [1, 2, 3, 4, 5] ,id(la)： 2684857868864
la： [1, 2, 3, 4, 5, 6, 7] ,id(la)： 2684857869248
y： [1, 2, 3, 4, 5] ,id(y)： 2684857868864

用 deepcopy 保护可变实参

如果实参是列表、集合、字典，又不希望函数里改到它，就在传参时复制一份：change_list(copy.deepcopy(y))。深拷贝的规则和浅拷贝的差别见 30.深拷贝与浅拷贝。

import copy

def change_list(la):
    print("la：", la, ",id(la)：", id(la))   # 内容与 y 相同，但地址不同
    la.append(3)
    print("la：", la, ",id(la)：", id(la))

y = [1, 2]
print("y：", y, ",id(y)：", id(y))
change_list(copy.deepcopy(y))
print("y：", y, ",id(y)：", id(y))            # y 内容和地址都不变

y： [1, 2] ,id(y)： 2684857869120
la： [1, 2] ,id(la)： 2684857868864
la： [1, 2, 3] ,id(la)： 2684857868864
y： [1, 2] ,id(y)： 2684857869120

嵌套调用

在一个函数里调用另一个函数，内层调用执行完之后，外层函数才继续往下走：

def print_info_a():
    print("print_info_a函数开始执行...")
    print_info_b()
    print("print_info_a函数执行完毕...")

def print_info_b():
    print("\tprint_info_b函数开始执行...")
    print("\tprint_info_b函数执行完毕...")

print_info_a()

print_info_a函数开始执行...
	print_info_b函数开始执行...
	print_info_b函数执行完毕...
print_info_a函数执行完毕...

递归

递归是函数在执行过程中调用自己：把复杂问题分解成同类但规模更小的子问题，一步步简化到可以直接解决的程度。

递归必须有两个要素：

  • 基础情况（Base Case）：递归的终止条件，最简单、可以直接求解的情况，用来防止无限递归。
  • 递归情况（Recursive Case）：调用自身的部分，把问题转成规模更小的同类问题，逐步向基础情况靠近。

缺了基础情况，或者递归没有真的朝基础情况靠近，就会一直调用下去。

阶乘：循环与递归

不用递归：

def factorial_loop(n):
    """
    计算n的阶乘：5! = 5 * 4 * 3 * 2 * 1
    """
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print("factorial_loop(5)=", factorial_loop(5))

factorial_loop(5)= 120

用递归。n <= 1 是基础情况，n * factorial_recursion(n - 1) 是递归情况：

def factorial_recursion(n):
    """
    计算n的阶乘：
       5! = 5 * 4!
       4! = 4 * 3!
       3! = 3 * 2!
       2! = 2 * 1!
       1! = 1
    """
    if n <= 1:
        return 1
    return n * factorial_recursion(n - 1)

print("factorial_recursion(5)=", factorial_recursion(5))

factorial_recursion(5)= 120

递归的执行过程

调用 factorial_recursion(5) 后，函数一层层往里调用直到 factorial_recursion(1) 返回 1，再一层层往外把结果乘回去，最后得到 120：

把调用和返回都打出来看得更清楚：

def factorial_trace(n, depth=0):
    print("  " * depth + f"factorial_trace({n})")
    if n <= 1:
        print("  " * depth + "返回 1")
        return 1
    r = n * factorial_trace(n - 1, depth + 1)
    print("  " * depth + f"返回 {n} * {r // n} = {r}")
    return r

factorial_trace(5)

factorial_trace(5)
  factorial_trace(4)
    factorial_trace(3)
      factorial_trace(2)
        factorial_trace(1)
        返回 1
      返回 2 * 1 = 2
    返回 3 * 2 = 6
  返回 4 * 6 = 24
返回 5 * 24 = 120

循环与递归的取舍

循环递归
代码通常更长更贴近数学定义，写起来短
运行开销小每次调用都要压栈，开销大
深度限制无受 sys.getrecursionlimit() 限制（默认 1000），超了抛 RecursionError
适用线性、可累加的问题树、图、分治等天然递归的结构

阶乘这类问题循环更划算。递归真正省事的地方是处理目录树、树形结构、分治算法。同一个问题如果递归里反复算同一批子问题（比如朴素斐波那契），复杂度会急剧膨胀，这时要改成循环、记忆化或动态规划。

Warning

递归忘写基础情况，或子问题规模没有变小，都会无限递归，最终抛 RecursionError: maximum recursion depth exceeded。Python 没有尾调用优化，递归深度大时优先改写成循环。

函数是一等公民

Python 里函数是一等公民，它本身也是对象，有自己的类型：

def my_function():
    print("我是函数体")

print(type(my_function))
print(my_function.__name__)

<class 'function'>
my_function

因此函数可以赋值给变量、作为参数传给别的函数、作为返回值、存进容器。高阶函数、闭包、装饰器都建立在这一点上。

赋值给变量

def greet():
    print("Hello!")

say_hello = greet    # 注意 greet 后面没有 ()
say_hello()
print(say_hello is greet)

Hello!
True

Warning

say_hello = greet 得到的是函数本身；say_hello = greet() 得到的是调用结果（这里是 None），之后 say_hello() 会报 TypeError: 'NoneType' object is not callable。

作为参数传递

def say_hi():
    print("Hi!")

def call_function(func):
    func()

call_function(say_hi)   # say_hi 作为实参传进去

Hi!

作为返回值

def get_function():
    def inner_function():
        print("Inner function")
    return inner_function

func = get_function()   # 得到的是一个函数
func()

Inner function

存入容器

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    return a / b

operations = [add, subtract, multiply, divide]
for operation in operations:
    print(operation.__name__, ": ", operation(5, 3))

add :  8
subtract :  2
multiply :  15
divide :  1.6666666666666667

lambda

lambda 用来定义匿名函数，不需要 def：

lambda 参数列表: 表达式
  • lambda 是表达式而不是语句，可以写在任何需要表达式的位置（实参、返回值、字典的值里）。
  • 主体只能是一个表达式，不能写代码块，所以只适合封装很短的逻辑。
  • lambda 也是函数，同样按 LEGB 规则查找变量，能访问外层和全局名字，详见 LEGB。

作为自定义函数的参数

def operate(a, b, func):
    return func(a, b)

print(operate(5, 2, lambda a, b: a + b))
print(operate(5, 2, lambda a, b: a - b))
print(operate(5, 2, lambda a, b: a * b))
print(operate(5, 2, lambda a, b: a / b))

7
3
10
2.5

作为内置函数的参数

sorted：排序、filter：过滤筛选、map ：映射转换，都接收一个函数作为参数，lambda 最适合写这种一次性的小函数：

student_list = [{"name": "zhang3", "age": 36}, {"name": "li4", "age": 14}, {"name": "wang5", "age": 27}]

student_list = sorted(student_list, key=lambda s: s["age"])
print("按照年龄排序：", student_list)

filter_result = filter(lambda s: s["age"] > 18, student_list)
print("18岁以上的：", list(filter_result))

map_result = map(lambda s: s["name"], student_list)
print("姓名：", list(map_result))

按照年龄排序： [{'name': 'li4', 'age': 14}, {'name': 'wang5', 'age': 27}, {'name': 'zhang3', 'age': 36}]
18岁以上的： [{'name': 'wang5', 'age': 27}, {'name': 'zhang3', 'age': 36}]
姓名： ['li4', 'wang5', 'zhang3']
  • sorted(iterable, key=...)：按 key 返回的值排序，列表自带方法 sort() 的用法见 排序与反转。
  • filter(func, iterable)：保留 func 返回真值的元素，返回迭代器。
  • map(func, iterable)：对每个元素调用 func，返回迭代器。filter、map 返回的都是迭代器，要看到结果得转成 list。

作为标准库函数的参数

functools.reduce 对可迭代对象做累积计算，heapq.nlargest / nsmallest 取最大或最小的 n 个元素，都用得上 lambda：

import functools
import heapq

list_demo = [3, 5, 6, 2, 1, 8, 4, 9, 10]
print("累加：", functools.reduce(lambda a, b: a + b, list_demo))
print("最大值：", functools.reduce(lambda a, b: a if a > b else b, list_demo))
print("最小值：", functools.reduce(lambda a, b: a if a < b else b, list_demo))
print("最大的3个偶数：", heapq.nlargest(3, list_demo, key=lambda x: x if x % 2 == 0 else float('-inf')))
print("最小的3个奇数：", heapq.nsmallest(3, list_demo, key=lambda x: x if x % 2 != 0 else float('inf')))

累加： 48
最大值： 10
最小值： 1
最大的3个偶数： [10, 8, 6]
最小的3个奇数： [1, 3, 5]

heapq.nlargest 的两行是同一个套路：用 key 把不想要的元素映射成 -inf（或 inf），它们就排不到前面。取第 n 大用 heapq.nlargest(n, ...) 比先 sorted 再切片快。

作为函数的返回值

配合 match-case，可以让一个函数按名字返回不同的运算函数：

def get_func(operate_name):
    match operate_name:
        case "add":
            return lambda a, b: a + b
        case "sub":
            return lambda a, b: a - b
        case "mul":
            return lambda a, b: a * b
        case "div":
            return lambda a, b: a / b
        case _:
            return None

func = get_func("add")
print(f"{func.__name__}的结果：", func(1, 2))

<lambda>的结果： 3

Note

lambda 没有名字，__name__ 都是 '<lambda>'。需要看得懂的名字或要写多行逻辑时，还是用 def。

说明文档与 help()

函数体第一行的字符串是文档字符串（docstring），用三引号，单双引号都可以。写好人人都受益：IDE 能显示提示，help() 能直接查看，自动化工具能生成 API 文档。

def is_prime(num):
    """
    判断num是否是素数
    :param num: 待判断的整数
    :return: 如果是素数返回True，否则返回False
    """
    if num < 2:
        return False
    import math
    for i in range(2, int(math.sqrt(num) + 1)):
        if num % i == 0:
            return False
    return True

print("7是素数吗？", is_prime(7))
help(is_prime)

7是素数吗？ True
Help on function is_prime in module __main__:

is_prime(num)
    判断num是否是素数
    :param num: 待判断的整数
    :return: 如果是素数返回True，否则返回False

docstring 存放在函数的 __doc__ 属性里，help() 会把它排版后打印出来。

函数注解

Python 3 起可以给参数和返回值加注解：参数后面用 : 写注解，返回值用 -> 写。注解内容可以是任何表达式——类型、说明文字、取值范围都行；所有注解都存进函数的 __annotations__ 属性，不影响调用，也不影响默认值的使用。

def print_info_normal(name, species, age):
    print(f"{name} 的品种是：{species}，年龄是：{age}")

print_info_normal("旺财", "泰迪", 5)
print(print_info_normal.__annotations__)

def print_info_special(name: str, species: str, age: int = 1) -> None:
    """
    打印狗的基本信息
    :param name: 狗的名称
    :param species: 狗狗的品种
    :param age: 狗狗的年龄，范围[1,99]
    :return: None
    """
    print(f"{name} 的品种是：{species}，年龄是：{age}")

print_info_special("旺财", "泰迪")
print(print_info_special.__annotations__)

旺财 的品种是：泰迪，年龄是：5
{}
旺财 的品种是：泰迪，年龄是：1
{'name': <class 'str'>, 'species': <class 'str'>, 'age': <class 'int'>, 'return': None}

没有注解的函数，__annotations__ 是空字典。注解也可以是字符串或任意表达式：

def print_info_any(name: str, species: "狗狗的品种", age: (1, 99) = 1) -> "返回None":
    print(f"{name} 的品种是：{species}，年龄是：{age}")

print_info_any("旺财", "泰迪")
print(print_info_any.__annotations__)

旺财 的品种是：泰迪，年龄是：1
{'name': <class 'str'>, 'species': '狗狗的品种', 'age': (1, 99), 'return': '返回None'}

注解只是存起来供人和工具查看，Python 运行时不做类型检查，写 print_info_special("旺财", "泰迪", "三岁") 照样能跑。函数注解是类型提示的基础，类型提示、TypeVar、Generic 与 mypy 检查见 33.类型注解与泛型。
