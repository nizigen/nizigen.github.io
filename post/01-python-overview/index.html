PYTHON

计算机先驱

  • 艾伦·图灵（Alan Turing）：提出"图灵机"这一抽象计算模型，为计算机科学奠定理论基础；1950 年提出"图灵测试"，ACM 以他的名字设立了计算机界最高奖"图灵奖"。
  • 约翰·冯·诺依曼（John von Neumann）：1945 年提出存储程序原理，确立了计算机由运算器、控制器、存储器、输入设备、输出设备五部分组成，并以二进制作为数制基础。

计算机组成

软件

类型作用
系统软件直接管理和控制硬件，为应用软件提供运行平台，负责协调内存、处理器等资源并提供文件管理、设备控制、任务调度等通用服务
应用软件为完成特定任务而编写，满足用户的具体需求，如文档编辑、数据分析、娱乐；依赖系统软件提供的资源和服务

硬件

计算机硬件由五部分组成：运算器、控制器、存储器、输入设备、输出设备。

计算机语言

计算机语言是人与计算机交流的工具，用它写出来的文字叫代码，一组完成特定任务的代码叫程序。

计算机语言简史

世代语言特点优点缺点
第 1 代机器语言由 0 和 1 组成的二进制指令，又称机器码机器可直接执行，速度最快人极难读写和维护；完全依赖硬件，无法移植
第 2 代汇编语言用 MOV、ADD 等助记符代替二进制指令，是机器语言的"人性化翻译"比机器语言易读写，执行效率高仍依赖特定 CPU 指令集；编程效率低，代码量大
第 3 代高级语言接近自然语言，屏蔽大部分底层细节，如 C、C++、Java、Go、Rust、JavaScript、Python易学易用，代码简洁，硬件无关，库和工具丰富需要编译或解释，效率较低；对硬件的控制力弱

早期的机器语言需要拨动开关、插拔连线或使用打孔纸带来输入指令：

同样是计算 1 + 1，三代语言的写法对比如下（x86 架构）。

机器语言：

10110000 00000001 00000100 00000001

汇编语言：

mov al, 1
add al, 1

Python：

print(1 + 1)

Note

CPU 只认二进制指令，所以汇编语言和高级语言都必须先转换成机器码才能执行。

编译型与解释型

高级语言按"转换成二进制指令"的方式不同，分为编译型和解释型。

类型转换方式常见语言优势劣势
编译型先把整个程序翻译成可执行文件（Windows 上是 .exe），之后直接运行C、C++、Go、Rust同一平台只需编译一次，执行效率高跨平台性差，大型项目编译耗时，开发效率略低
解释型运行时一句一句翻译，通常不生成可执行文件Python、PHP、JavaScript跨平台性好，无需编译，开发调试灵活每次运行都要解释，执行效率较低
编译 + 解释混合先编译成字节码，再由虚拟机解释执行或即时编译（JIT）Java兼顾启动速度与运行性能机制较复杂

Java 的执行过程是：源码 .java → 编译 → 字节码 .class → 解释或 JIT 编译 → 机器码执行。

Python 同样是"先隐式编译成字节码，再由虚拟机解释执行"，但标准实现 CPython 没有 JIT 这一步优化，所以通常不称它为混合型语言。

特性JavaPython（CPython）
编译产出显式生成 .class 字节码文件隐式生成字节码，被导入的模块会缓存为 .pyc
执行引擎解释器 + JIT 编译器（如 HotSpot）纯解释器
性能核心JIT 把热点字节码编译成优化后的机器码解释器直接执行字节码
“混合"的含义编译 + 解释 + 即时编译，追求峰值性能编译 + 解释，服务于跨平台和开发便利

Tip

结论：Python 是高级语言，是解释型语言。

Note

.pyc 保存在模块所在目录的 __pycache__ 下。直接运行的入口脚本不会生成 .pyc，只有被 import 的模块才会。

TIOBE 排行

TIOBE 排行榜由荷兰 TIOBE 公司从 2001 年起按月发布，数据来自主流搜索引擎的查询结果，衡量的是语言在开发者社区的关注度和讨论热度，不等于"最好用"或"代码量最多”。它可以作为学习与技术选型的风向标之一，网址：https://www.tiobe.com/tiobe-index/

Python 语言概述

起源

Python 的作者 Guido van Rossum 来自荷兰，国内常称"龟叔"，1982 年从阿姆斯特丹大学获得数学和计算机硕士学位。他嫌用 C、Fortran 写程序太费劲，而 Shell 又功能有限，于是在 1989 年圣诞节开始编写一种既能像 C 那样全面操控系统、又像 Shell 那样容易上手的解释器，并以喜剧《Monty Python’s Flying Circus》命名为 Python。

Python 的设计哲学是"优雅、明确、简单"，提倡最好只有一种方法来做一件事。第一个公开版本发布于 1991 年。

特点

优点：

  • 易学易用：语法简洁、可读性强、代码结构清晰，上手难度低。
  • 开发效率高：内置网络通信、文本处理、数据库、图形系统等功能，社区提供 Web 开发、科学计算、人工智能等领域的模块。
  • 跨平台运行：同样的代码可以在 Windows、Linux、macOS 等平台上运行。
  • 应用领域广：自动化脚本、桌面工具；数据处理与科学计算（Pandas、NumPy）；网络爬虫（Requests、BeautifulSoup）；Web 开发（Flask、Django）；AI 与机器学习（TensorFlow、PyTorch）。

缺点：

  • 运行速度较慢：解释型语言，运行时要由解释器翻译成机器码再执行，不像 C、C++ 那样事先编译。
  • 代码无法加密：发布的 .py 文件很容易被查看源码逻辑，保护知识产权略显困难。
  • 内存消耗略大：相比 C、C++ 这类紧凑型语言更"吃内存"，不太适合资源受限的设备，如部分微控制器。

版本

Python 有 Python 2 和 Python 3 两个系列。Python 3.0 在设计时没有考虑向下兼容，许多早期程序无法在 3.x 上直接运行，但如今大部分新项目和三方库都已转向 Python 3，Python 3.x 是现在和未来的主流。

时间事件
2008 年Python 3.0 发布
2020 年Python 2 官方停止维护，2.7 是最后一个 2.x 版本；Python 3.9 发布
2021 年Python 3.10 发布
2022 年Python 3.11 发布，官方称平均性能提升约 10%~60%
2023 年Python 3.12 发布，进一步优化性能和类型提示
2024 年Python 3.13 发布
2025 年Python 3.14 发布

课程使用的版本是 Python 3.12.8。本笔记中新语法会标注最低版本，例如 match-case 需要 3.10+。

解释器

Python 从规范到解释器都是开源的，所以存在多种解释器实现。

解释器说明
CPython官网下载安装的官方解释器，用 C 语言开发，使用最广，本笔记所有代码都在它上面运行；命令行中的提示符是 >>>
IPython基于 CPython 的交互式解释器，只增强交互方式（提示符为 In [序号]:），执行代码的能力与 CPython 一致
PyPy目标是执行速度，采用 JIT 技术动态编译，可显著提速；但与 CPython 有差异，同样的代码结果可能不同
Jython运行在 Java 平台上，把 Python 代码编译成 Java 字节码
IronPython运行在微软 .NET 平台上，把 Python 代码编译成 .NET 字节码

Tip

如果要和 Java 或 .NET 平台交互，更好的办法不是用 Jython 或 IronPython，而是通过网络调用来交互，保证各程序之间的独立性。

为什么 Python 是"AI 时代的通用语"

Python 不是性能最好的语言，但在 AI 领域几乎是默认选择：

  • 生态壁垒：PyTorch、TensorFlow 的前端 API 都是 Python，英伟达对 Python 的 GPU 支持最完善，新模型发布后很快就有 Python 实现。
  • 开发效率：AI 是实验科学，需要频繁改网络层、换激活函数。Python 无需编译、即写即跑，配合 Jupyter 可以边写边看数据形状。慢的是运行速度，快的是人的决策速度。
  • 胶水特性：矩阵乘法、卷积等重活由底层 C、C++、CUDA 完成，Python 只负责调库和编排计算流程。

在 AI 相关工程里，其他语言通常各管一段：C++ 写推理引擎和算子，让模型跑得快；Go 写服务网关和微服务治理，让服务稳；Java 用于大厂推荐系统的高并发在线服务。
