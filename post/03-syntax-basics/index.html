注释

注释是对代码的解释说明，用来提高可读性、临时屏蔽暂时不需要的代码，也有助于定位程序中出错的位置。

单行注释

单行注释以 # 开头，可以单独一行，也可以写在代码行尾。建议 # 之后留 1 个空格，行尾注释与代码之间留 2 个空格。

# 这是一个单行注释
print("hello")  # 这是一个输出语句

多行注释

Python 会忽略没有赋给变量的字符串字面量，所以三个单引号或三个双引号括起来的文本块可以当作多行注释使用。

"""
    Python 中 3 个单引号、3 个双引号引起来的文本块可以被看成多行注释。
    建议每个 .py 文件顶部的文档注释使用 3 个双引号。
"""

# 赋给变量就不再是注释，而是一个普通的多行字符串
info = """
    尚硅谷
        让天下有学不完的技术
"""
print(info)

  • 单行注释可以嵌套在多行注释中，不会引起语法错误。
  • 同种引号的多行注释不能嵌套：第一个三引号之后的内容直到下一个三引号都被当作字符串，中间多出来的三引号会让后面的部分出错。运行结果：SyntaxError: unterminated triple-quoted string literal。
  • 不同种引号可以互相嵌套，例如在 """ 块内写 '''内层''' 不会报错。

文档注释

文档注释位于 .py 文件开头，用三个双引号开头和结尾，有固定的格式（如作者、时间、描述），用来说明当前源文件。

"""
    @Author:Irene
    @Time:2026/1/28
    @Desc:这是文档注释，即当前源文件中的代码说明
"""

缩进

Python 采用代码缩进和冒号（ : ）来区分代码块之间的层次。

在 Python 中，对于类定义、函数定义、流程控制语句、异常处理语句等，行尾的冒号和下一行的缩进，表示下一个代码块的开始，而缩进的结束则表示此代码块的结束。

  • 缩进可以用空格或 Tab 键实现，但无论哪种，通常都采用 4 个空格长度作为一个缩进量（多数编辑器默认一个 Tab 表示 4 个空格）。PEP 8 同样建议每级缩进使用 4 个空格。
  • 同一个级别代码块的缩进量必须一样，否则解释器会报 IndentationError（SyntaxError 的子类）。
  • 不要混用制表符和空格，混用会让解释器无法判断层级，抛出 TabError。可以在编辑器里把输入的 Tab 自动转换成空格，使用时仍然可以按 Tab 键。
  • IDLE 中可用 Ctrl+] 和 Ctrl+[ 让选中的多行代码一起缩进或反缩进；PyCharm 中是 Tab 和 Shift + Tab。

a = 30
b = 20
if a > b:
    print("a > b")
elif a == b:
    print("a = b")
else:
    print("a < b")

nums = [1, 2, 3]
for num in nums:
    if num == 2:
        continue
    print(num)

a > b
1
3

缩进不一致时的报错：

x = 1
    y = 2

IndentationError: unexpected indent

if True:
    a = 1
   b = 2

IndentationError: unindent does not match any outer indentation level

Note

同一行写多条语句时用分号分隔，语法上可行，但不推荐，也不要在行尾加分号，详见 编码规范。

标识符与命名

凡是需要程序员自己命名的部分，都称为标识符，例如文件名（模块名）xx.py、变量名、常量名、函数名、类名。

命名规则

规则是语法层面的要求，违反会报错，必须遵守：

（1）标识符必须以字母或下划线字符开头 （2）标识符称不能以数字开头 （3）标识符不能和 Python 中的保留字相同。 （4) python中的标识符中，不能包含空格、@、% 以及 $ 等特殊字符。 (5) 标识符名称区分大小写（age、Age 和 AGE 是三个不同的变量）

Python 语言中，以下划线开头的标识符有特殊含义：

  • 以单下划线开头的标识符（如_width），表示不能直接访问的类属性，其无法通过 from…import* 的方式导入；
  • 以双下划线开头的标识符（如__add）表示类的私有成员；
  • 以双下划线作为开头和结尾的标识符（如 init），是专用标识符。 因此，除非特定场景需要，应避免使用以下划线开头的标识符。

私有成员、名称改写和魔法方法的细节见 封装。

违反规则时的报错：

class = 1      # SyntaxError: invalid syntax，关键字不能当标识符
1abc = 1       # SyntaxError: invalid decimal literal，不能以数字开头
my var = 1     # SyntaxError: invalid syntax，不能含空格

Tip

标识符中的字母不限于英文，姓名 = "张三" 也是合法的，但实际项目中建议使用英文，方便协作。

命名规范

规范是约定俗成的写法，不遵守不会报错，但尽量遵守，总原则是保证可读性好、见名知意。

风格写法常见用途例子
大驼峰（upper camel case）每个单词首字母大写，如 HelloWorldPython类、异常，常见ValueError、ZeroDivisionError、multiprocessing.Pool
小驼峰（lower camel case）第一个单词首字母小写，之后每个单词首字母大写，如 helloWorldPython变量、函数，但在 Python 中很少用unittest.TestCase.assertEqual
全小写所有单词小写变量、函数、方法、包、模块，常见random.randint、datetime.fromtimestamp
全大写所有单词大写常量，常见datetime.MAXYEAR、datetime.MINYEAR
蛇形（snake case）全小写或全大写的标识符，单词间用下划线连接，如 hello_world_python变量、函数名用小写，常量用大写；最常用_check_date_fields、_DAYS_IN_MONTH

按用途细分的约定：

  • 模块名：尽量短小，全部小写，可以用下划线分隔多个单词，如 game_main、game_register。
  • 包名：尽量短小，全部小写，不推荐使用下划线，如 com.mr、com.mr.book。
  • 类名：单词首字母大写，如图书类 Book；模块内部使用的类可以加下划线前缀，如 _Book。
  • 函数名、类的属性名和方法名：全部小写，多个单词用下划线分隔。
  • 常量：全部大写，单词之间用下划线分隔。
  • 不用下划线也不用驼峰（如 helloworldpython）会增加阅读难度。

关键字

关键字是语言预先保留的、具有特殊含义的单词，是语法的一部分，用于定义程序结构、控制流程等，不能用作变量名、函数名或其他自定义标识符。

标准库的 keyword 模块可以输出当前版本的所有关键字：

import keyword
print(keyword.kwlist)

运行结果（Python 3.13，共 35 个）：

['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await', 'break', 'class', 'continue', 'def', 'del', 'elif', 'else', 'except', 'finally', 'for', 'from', 'global', 'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 'not', 'or', 'pass', 'raise', 'return', 'try', 'while', 'with', 'yield']

Warning

导入的是标准库模块 keyword（单数，没有结尾的 s），并且通过 keyword.kwlist 访问列表。

记忆分类：

类别关键字
特殊值True、False、None
控制流if、elif、else、for、while
循环控制break、continue、pass
函数相关def、return、lambda、yield
异常处理try、except、finally、raise、assert
模块导入import、from、as
类与对象class、is、del、with
作用域global、nonlocal
逻辑运算and、or、not、in
异步编程async、await

Info

match、case（3.10+，模式匹配）和 type（3.12+，类型别名语句）只在特定语法位置有特殊含义，称为软关键字，不在 kwlist 里，可用 keyword.softkwlist 查看；match = 1 仍然合法。print 不是关键字，只是内置函数名，用 keyword.iskeyword("print") 返回 False。

变量

变量的本质是代表一块内存区域，其中的数据可以在程序运行期间被修改。在代码中，变量就是用一个标识符来表示一个数据，便于引用，例如 age = 18。

  • Python 中的变量不需要声明，对一个不存在的变量赋值就相当于创建了一个新变量。
  • 每个变量在使用前都必须赋值，赋值以后该变量才会被创建。
  • 变量可以通过重新赋值来改变，同一个变量甚至可以先后指向不同类型的数据。
x = 1
x = "s"
x = [1]
print(type(x))

<class 'list'>

Note

变量名本身没有类型，数据值才有类型（type() 查看的是数据的类型），所以 Python 是动态类型语言：书写时不必声明类型，但解释器内部仍然严格区分，例如 2 + "a" 会抛出 TypeError，不会自动转换。有些资料称它"弱类型"并不准确。类型相关内容见 数据类型与类型转换。

创建多个变量

变量名1 = 变量名2 = 变量名3 = 值          # 多个变量值相同
变量名1, 变量名2, 变量名3 = 值1, 值2, 值3  # 多个变量值不同

name = "张三"
age = 18
weight = 100.5
print("name = ", name, "age = ", age, "weight = ", weight)
age = 19        # 变量可以重新赋值
weight = 120.0  # 变量可以重新赋值
print("name = ", name, "age = ", age, "weight = ", weight)

a, b = 1, 2  # 创建多个变量
c = a + b
print("a = ", a, "b = ", b, "c = ", c)

x, y = 1, 2
print("x = ", x, "y = ", y)
x, y = y, x  # 交换 x, y 变量的值
print("x = ", x, "y = ", y)

name =  张三 age =  18 weight =  100.5
name =  张三 age =  19 weight =  120.0
a =  1 b =  2 c =  3
x =  1 y =  2
x =  2 y =  1

连续赋值和复合赋值见 赋值运算符。在函数内部创建的变量是局部变量，作用域规则见 global 与 nonlocal。

常量

在程序中定义后就不再修改的值称为常量。Python 没有内置的常量类型，一般约定用全大写的变量名表示常量。

PI = 3.1415926
E = 2.718282

print(PI)
print(E)

PI = 3.14  # 实际上可以修改，只是大家"默认"不会修改
print(PI)

3.1415926
2.718282
3.14

Warning

语法层面无法阻止对常量的修改，修改后也不会报错。“不允许修改"只是逻辑约定，而非语法强制。

Python 的设计哲学里有一句话"We are all consenting adults here”（我们都是成年人），意思是 Python 不会强制限制开发者的操作，更倾向于"约定优于强制"。详见 最小封装原则。
