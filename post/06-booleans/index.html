在编程中，经常需要知道一个表达式是 True 还是 False。Python 中任何表达式都可以求值，得到的结果要么是 True，要么是 False。

bool 是 int 的子类

布尔类型（bool）是整型（int）的子类型：布尔值是整数的一个特例。

  • True 本质上相当于整数 1。
  • False 本质上相当于整数 0。
  • isinstance(a, bool) 和 isinstance(a, int) 对布尔值都返回 True。

布尔值可以直接与整数、小数做数学运算，这是 Python 与 Java 等语言的重要区别。运算时 True 当作 1，False 当作 0。例如 a = True，print(a + 1) 输出 2。

a = True
b = 1
c = False
d = 0

print(a == b)
print(c == d)
print(a + 1)

print(a is b)
print(c is d)
print(isinstance(a, bool), isinstance(a, int))

真值测试

在 if 条件、while 循环等判断中，Python 会自动把其他类型转换为布尔值。

  • 视为 True：非零的数字、非空的字符串、非空的列表、元组、集合、字典等非空容器。
  • 视为 False：下表所列的值。
假值示例

flag = None
if flag:
    print("None")

flag = 0.0
if flag:
    print("0.0")

flag = ""
if flag:
    print("空字符串")

flag = []
if flag:
    print("空列表")

a = "hello"   # 非空字符串
if a:
    print("成立")
else:

自定义类的对象默认为真；如果类定义了 __bool__()（返回 False）或 __len__()（返回 0），则对象为假。

bool() 函数

bool() 函数可以评估任何值，返回 True 或 False。大多数值都是 True：只要有某种内容，几乎所有值都评估为 True。

  • 除空字符串外，任何字符串均为 True。
  • 除 0 外，任何数字均为 True。
  • 除空容器外，任何列表、元组、集合和字典均为 True。
print(bool("abc"))
print(bool(123))
print(bool(["apple", "cherry", "banana"]))

print(bool(False))
print(bool(None))
print(bool(0))
print(bool(""))
print(bool(()))
print(bool([]))
print(bool({}))

Warning

字符串 "False" 和 "0" 都是非空字符串，bool("False") 和 bool("0") 的结果都是 True。把用户输入转成布尔值时不能直接用 bool()，要先和具体的字符串比较。
