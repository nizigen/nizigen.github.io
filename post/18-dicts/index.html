PYTHON

Python 字典（dict）是无序、可变的序列，元素以"键值对（key-value）“的形式存储。列表和元组都是有序序列，元素在底层挨着存放，靠索引取值；字典靠键取值，是 Python 中唯一的映射类型。

“映射"是数学术语，指元素之间相互对应的关系：通过一个元素，可以唯一找到另一个元素。

字典中，各元素对应的索引称为键（key），各个键对应的元素称为值（value），键及其关联的值合称"键值对”。

主要特征解释
通过键而不是通过索引来读取元素字典也称为关联数组或散列表（hash）。它通过键把一系列值联系起来，可以通过键取值，但不能通过索引取值
字典是任意数据类型的无序集合列表、元组里索引值 0 对应的元素叫第一个元素，字典没有这种概念
字典是可变的，并且可以任意嵌套字典可以在原处增长或缩短，无需生成副本；值可以是列表、字典，支持任意深度的嵌套
字典中的键必须唯一同一个键不能出现多次，否则只保留最后一个键值对
字典中的键必须不可变键只能是数字、字符串或元组，不能是列表
scores = {'数学': 95, '英语': 92, '语文': 84}
print(scores)
print({(20, 30): 'great', 30: [1, 2, 3]})
print({'a': 1, 'a': 2})
try:
    {[1, 2]: 'x'}
except TypeError as e:
    print("列表当键：", type(e).__name__, e)

{'数学': 95, '英语': 92, '语文': 84}
{(20, 30): 'great', 30: [1, 2, 3]}
{'a': 2}
列表当键： TypeError unhashable type: 'list'

Info

老教程说"字典是无序的”，严格讲现在不准确：CPython 3.7 起（3.6 已是实现细节）字典按插入顺序保存和输出。但它仍然没有索引，不能按下标取值，所以本章仍把它归为无序容器。

创建字典

直接写 { }

dictname = {'key1': 'value1', 'key2': 'value2', ..., 'keyn': valuen}

键和值之间用冒号 : 分隔，相邻元素之间用逗号 , 分隔，所有元素放在大括号里。同一个字典中的键必须唯一。

dict1 = {}
print("dict1：", dict1)
dict2 = dict()
print("dict2：", dict2)
dict3 = {"name": "Irene", "age": 18, "sex": "female"}
print("dict3：", dict3)
dict4 = dict(name="Bob", age=20, gender="female")
print("dict4：", dict4)
dict5 = dict([("name", "Tom"), ("age", 22), ("gender", "male")])
print("dict5：", dict5)

dict1： {}
dict2： {}
dict3： {'name': 'Irene', 'age': 18, 'sex': 'female'}
dict4： {'name': 'Bob', 'age': 20, 'gender': 'female'}
dict5： {'name': 'Tom', 'age': 22, 'gender': 'male'}

{} 创建的是空字典，不是空元组也不是空集合。空集合只能写 set()，见 集合。

dict() 映射函数

dict() 有多种写法，传入的列表或元组里，每个元素又要各自是含 2 个元素的列表或元组，第一个元素作键、第二个作值：

demo = [('two', 2), ('one', 1), ('three', 3)]
print("dict(二维列表)：", dict(demo))
print("dict(二维元组)：", dict((('two', 2), ('one', 1), ('three', 3))))

dict(二维列表)： {'two': 2, 'one': 1, 'three': 3}
dict(二维元组)： {'two': 2, 'one': 1, 'three': 3}

用 dict() 配合 zip() 能把两个列表拼成字典：

keys = ['one', 'two', 'three']
values = [1, 2, 3]
print("dict(zip())：", dict(zip(keys, values)))

dict(zip())： {'one': 1, 'two': 2, 'three': 3}

fromkeys()

dictname = dict.fromkeys(list, value=None)

list 是所有键的列表，value 是默认值，不写则为 None。

knowledge = ['语文', '数学', '英语']
print(dict.fromkeys(knowledge, 60))

{'语文': 60, '数学': 60, '英语': 60}

这种方式通常用于初始化字典、给所有键设同一个默认值。

Warning

dict.fromkeys(keys, []) 里所有的键指向的是同一个列表，改其中一个，其余的也跟着变。需要各自独立时用字典推导式：{k: [] for k in keys}。

访问字典

列表和元组通过下标访问元素，字典通过键访问对应的值。字典中的元素没有固定位置，不能用切片一次性取多个。

dictname[key]

键必须存在，否则抛 KeyError。

get()

dictname.get(key[, default])

键不存在时 get() 不抛异常：不指定 default 返回 None，指定了就返回 default。

dict_demo = {"name": "Irene", "age": 18, "sex": "female"}
print(dict_demo["name"], dict_demo["age"], dict_demo["sex"])
print(dict_demo.get("name"), dict_demo.get("age"), dict_demo.get("sex"))
print("get 不存在的 key：", dict_demo.get("tel"))
print("get 带默认值：", dict_demo.get("tel", "该键不存在"))

try:
    dict_demo["tel"]
except KeyError as e:
    print("[] 取不存在的 key：", type(e).__name__, e)

Irene 18 female
Irene 18 female
get 不存在的 key： None
get 带默认值： 该键不存在
[] 取不存在的 key： KeyError 'tel'

Tip

get() 写起来短，还能顺手给默认值，比自己先 if key in d 再取值清楚。需要"取不到就写入默认值"的场景用 setdefault()，见下文。

判断键是否存在

in 和 not in 判断的是键，不是值：

dict_demo = {"name": "Irene", "age": 18, "sex": "female"}
print("name in dict：", "name" in dict_demo)
print("Irene in dict：", "Irene" in dict_demo)

name in dict： True
Irene in dict： False

所以想判断某个键值对是否存在，要先判断键，再用 dict[key] 取出值来比较。

增删改

添加键值对

直接给不存在的键赋值，或者用 update()：

dict_demo = {"name": "Irene", "age": 18, "sex": "female"}
dict_demo["tel"] = "1234567890"
print("添加tel：", dict_demo)
dict_demo.update({"email": "irene@gmail.com"})
print("添加email：", dict_demo)

添加tel： {'name': 'Irene', 'age': 18, 'sex': 'female', 'tel': '1234567890'}
添加email： {'name': 'Irene', 'age': 18, 'sex': 'female', 'tel': '1234567890', 'email': 'irene@gmail.com'}

修改值

字典中键的名字不能被修改，只能修改值。键唯一，所以新赋的值会覆盖同键的旧值：

dict_demo = {"name": "Irene", "age": 18, "sex": "female"}
dict_demo["name"] = "lily"
print("修改name：", dict_demo)
dict_demo.update({"name": "lucy"})
print("修改name：", dict_demo)

修改name： {'name': 'lily', 'age': 18, 'sex': 'female'}
修改name： {'name': 'lucy', 'age': 18, 'sex': 'female'}

update() 用一个字典的键值对来更新已有字典：键已存在则覆盖原值，键不存在则添加进去。

a = {'one': 4, 'two': 2, 'three': 3}
b = {'one': 4.5, 'four': 9.3}
a.update(b)
print(a)

{'one': 4.5, 'two': 2, 'three': 3, 'four': 9.3}

删除键值对

dict_demo = {"name": "Irene", "age": 18, "sex": "female", 'tel': '1234567890',
             'email': 'irene@gmail.com'}
print("删除前：", dict_demo)

popped = dict_demo.pop("name")
print(f"pop('name') 返回 {popped}，之后：", dict_demo)

item = dict_demo.popitem()
print(f"popitem() 返回 {item}，之后：", dict_demo)

del dict_demo["age"]
print("del age 之后：", dict_demo)

dict_demo.clear()
print("clear() 之后：", dict_demo)

删除前： {'name': 'Irene', 'age': 18, 'sex': 'female', 'tel': '1234567890', 'email': 'irene@gmail.com'}
pop('name') 返回 Irene，之后： {'age': 18, 'sex': 'female', 'tel': '1234567890', 'email': 'irene@gmail.com'}
popitem() 返回 ('email', 'irene@gmail.com')，之后： {'age': 18, 'sex': 'female', 'tel': '1234567890'}
del age 之后： {'sex': 'female', 'tel': '1234567890'}
clear() 之后： {}

d = {'a': 1}
print("pop 带默认值：", d.pop('b', '不存在'))
try:
    d.pop('b')
except KeyError as e:
    print("pop 无默认值：", type(e).__name__, e)
try:
    {}.popitem()
except KeyError as e:
    print("空字典 popitem：", type(e).__name__, e)

pop 带默认值： 不存在
pop 无默认值： KeyError 'b'
空字典 popitem： KeyError 'popitem(): dictionary is empty'
  • pop(key) 删除指定键值对并返回对应的值，不写 default 时键不存在会抛 KeyError。
  • popitem() 删除最后插入的键值对并以元组返回，字典为空会抛 KeyError。

Note

很多老教程写"popitem() 随机删除一个键值对"，这不准确。键值对在底层有存储顺序，popitem() 总是弹出最后插入的那一个，和列表的 pop() 类似，实现的是"出栈"的操作。

遍历字典

dict_demo = {"name": "Irene", "age": 18, "sex": "female"}

# 遍历所有 key
for key in dict_demo:
    print(key, end=" ")
print()

# 遍历所有 value
for value in dict_demo.values():
    print(value, end=" ")
print()

# 遍历所有键值对
for key, value in dict_demo.items():
    print(key, "->", value)

name age sex 
Irene 18 female 
name -> Irene
age -> 18
sex -> female

for key in dict_demo 等价于 for key in dict_demo.keys()，遍历的是键。要值用 .values()，要键和值一起用 .items()。

视图对象

keys()、values()、items() 返回的不是列表，而是视图对象 dict_keys、dict_values、dict_items。视图不复制数据，字典一变，视图跟着变：

d = {"name": "Irene", "age": 18}
print(d.keys(), d.values(), d.items())
print(type(d.keys()).__name__, type(d.values()).__name__, type(d.items()).__name__)

v = d.keys()
d["sex"] = "female"
print("字典改变后视图跟着变：", list(v))

dict_keys(['name', 'age']) dict_values(['Irene', 18]) dict_items([('name', 'Irene'), ('age', 18)])
dict_keys dict_values dict_items
字典改变后视图跟着变： ['name', 'age', 'sex']

Python 3.x 不想让用户直接操作这几个返回值。要当成列表用有两种方案：用 list() 转换（list(d.keys()) → ['name', 'age', 'sex']），或者直接 for ... in 遍历。

Warning

在 for key in d 循环里给 d 添加或删除键会抛 RuntimeError: dictionary changed size during iteration。要改就先 list(d.items()) 复制一份再遍历。

字典推导式

字典推导式用 {键表达式: 值表达式 for 元素 in 可迭代对象} 直接生成字典，放在四种推导式的总览里就是第三条，见 列表推导式。

print({x: x ** 2 for x in range(1, 6)})
print({x: x ** 2 for x in range(1, 6) if x % 2 == 0})

words = ["apple", "banana", "cherry"]
print({w: len(w) for w in words})

print({v: k for k, v in {"a": 1, "b": 2}.items()})

keys = ['one', 'two', 'three']
values = [1, 2, 3]
print({k: v for k, v in zip(keys, values)})

{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
{2: 4, 4: 16}
{'apple': 5, 'banana': 6, 'cherry': 6}
{1: 'a', 2: 'b'}
{'one': 1, 'two': 2, 'three': 3}
  • 条件 if 写在 for 后面是筛选。
  • 键值互换、从两列数据组装字典都很方便。
  • 键必须可哈希，表达式算出列表会直接报 TypeError。

setdefault()

dictname.setdefault(key, defaultvalue)

setdefault() 总能返回指定键对应的值：键已存在，直接返回原有的值（defaultvalue 被忽略）；键不存在，先把这个键和 defaultvalue 写进字典，再返回 defaultvalue。

a = {'数学': 95, '语文': 89, '英语': 90}
print(a)
print("setdefault('物理', 94) 返回：", a.setdefault('物理', 94))
print(a)
print("setdefault('化学') 返回：", a.setdefault('化学'))
print(a)
print("setdefault('数学', 100) 返回：", a.setdefault('数学', 100))
print(a)

{'数学': 95, '语文': 89, '英语': 90}
setdefault('物理', 94) 返回： 94
{'数学': 95, '语文': 89, '英语': 90, '物理': 94}
setdefault('化学') 返回： None
{'数学': 95, '语文': 89, '英语': 90, '物理': 94, '化学': None}
setdefault('数学', 100) 返回： 95
{'数学': 95, '语文': 89, '英语': 90, '物理': 94, '化学': None}

键已存在时 setdefault() 不会改值，只是把原值返回。它常用来给字典做"分组"的初始化。

copy() 浅拷贝

copy() 返回一个具有相同键值对的新字典：

a = {'one': 1, 'two': 2, 'three': [1, 2, 3]}
b = a.copy()
print("b：", b)

a['four'] = 100
print("a：", a)
print("b：", b)

a['three'].remove(1)
print("a：", a)
print("b：", b)
print("内层列表是同一对象：", a['three'] is b['three'])

b： {'one': 1, 'two': 2, 'three': [1, 2, 3]}
a： {'one': 1, 'two': 2, 'three': [1, 2, 3], 'four': 100}
b： {'one': 1, 'two': 2, 'three': [1, 2, 3]}
a： {'one': 1, 'two': 2, 'three': [2, 3], 'four': 100}
b： {'one': 1, 'two': 2, 'three': [2, 3]}
内层列表是同一对象： True

copy() 对最表层的键值对做的是深拷贝：它另外申请一块内存存放新的键值对集合，所以给 a 添加 'four' 不影响 b。但对值里的列表，做的是浅拷贝：b 里的 [1, 2, 3] 不是自己独有的，而是和 a 共用同一个列表对象，所以改 a['three'] 的内容，b 也跟着变。

要连内层一起复制，用 copy.deepcopy()，完整原理见 深拷贝与浅拷贝。

合并运算符 |

| 把两个字典合并成一个新字典，键相同时右边的覆盖左边，原字典都不变；|= 是就地更新，等价于 update()。两者都需要 Python 3.9+。

a = {"one": 1, "two": 2}
b = {"two": 20, "three": 3}
print("a | b =", a | b)
print("合并后 a：", a)

a |= b
print("a |= b 之后 a：", a)

a | b = {'one': 1, 'two': 20, 'three': 3}
合并后 a： {'one': 1, 'two': 2}
a |= b 之后 a： {'one': 1, 'two': 20, 'three': 3}

常用函数一览

方法 / 函数说明
del dict[key]根据 key 删除键值对
dict.pop(key[, default])获取 key 对应的 value 并删除该键值对，可设置默认值
dict.popitem()取出最后插入的键值对，字典为空则报错
dict.clear()清空字典
dict1.update(dict2)将 dict2 的键值对更新到 dict1 中
dict1 | dict2合并两个字典，返回新字典（3.9+）
dict.get(key[, default])获取 key 对应的 value，可设置默认值
dict.setdefault(key[, default])获取 key 对应的 value；key 不存在时先写入并把它设为默认值
dict.keys()获取所有 key，返回视图对象
dict.values()获取所有 value，返回视图对象
dict.items()获取所有 (key, value)，返回视图对象
dict.copy()浅拷贝字典
dict.fromkeys(seq[, default])以序列 seq 的元素为 key 创建新字典，可设置 value 的默认值
len(dict)返回键值对个数
key in dict判断 key 是否存在

用字典格式化字符串

当字符串模板里包含大量转换说明符时，按顺序提供变量很麻烦。可以在模板里按 key 指定变量，再用字典为这些 key 传值：

temp = '教程是：%(name)s, 价格是：%(price).2f, 网址是：%(url)s'
course = {'name': 'Python教程', 'price': 9.9, 'url': 'http://c.biancheng.net/python/'}
print(temp % course)

course = {'name': 'C++教程', 'price': 15.6, 'url': 'http://c.biancheng.net/cplus/'}
print(temp % course)

教程是：Python教程, 价格是：9.90, 网址是：http://c.biancheng.net/python/
教程是：C++教程, 价格是：15.60, 网址是：http://c.biancheng.net/cplus/

%(key)s 取字典中 key 对应的值，%(key).2f 还能顺便控制小数位。% 占位符、str.format()、f-string 的完整对比见 字符串格式化，日常更多用 format(**course) 或 f-string。
