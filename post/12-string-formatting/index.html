PYTHON

格式化指的是把变量的值按指定的样子放进字符串里。Python 有三种写法，本篇是它们的唯一详述处，输入输出、字符串、字典 只链接到这里。

写法例子说明
% 格式化"%s %d" % (name, age)最早的写法，源自 C 语言的 printf
str.format()"{} {}".format(name, age)功能完整，位置和名称都可以指定
f-stringf"{name} {age}"3.6 引入，直接在字符串里写表达式，最常用

后两种共用同一套“格式控制”规则，见下面的格式控制小节。

% 格式化

转换说明符

字符串里的转换说明符（Conversion Specifier）只是占位符，会被 % 后面表达式的值代替。% 前面是格式化字符串，后面是要输出的值。

格式符号说明
%d、%i带符号的十进制整数
%o八进制整数
%x、%X十六进制整数（小写、大写）
%e、%E科学计数法浮点数（小写、大写）
%f、%F十进制浮点数
%g、%G智能选择 %f 或 %e 格式
%c单个字符，参数可以是整数码点或长度为 1 的字符串
%r用 repr() 转成字符串
%s用 str() 转成字符串
%%输出一个 % 字符
age = 21
print("我今年%d岁了！" % age)

name = "chiyuki"
url = "http://chiyuki20.github.com"
print("%s已经%d岁了，它的网址是%s。" % (name, age, url))

a = 1
b = 2.5
print("a = %d, b = %f" % (a, b))

print("%d %o %x %X %e %f %g %c %r %s" % (65, 65, 255, 255, 12345.678, 3.14, 0.00001234, 65, "hi", "hi"))
print("完成了 %d%%" % 50)

我今年21岁了！
chiyuki已经21岁了，它的网址是http://chiyuki20.github.com。
a = 1, b = 2.500000
65 101 ff FF 1.234568e+04 3.140000 1.234e-05 A 'hi' hi
完成了 50%

格式化字符串里有多个转换说明符时，要提供同样多的值，并且必须用小括号 ( ) 包成元组。

Warning

值的个数与占位符不一致会报 TypeError: not enough arguments for format string；%d 遇到字符串会报 TypeError。要格式化的值本身是元组时，需要再包一层："%s" % ((1, 2),)。

最小输出宽度

在 % 和格式符号之间写数字，指定至少占用多少个字符：%10d 表示整数至少宽 10，%20s 表示字符串至少宽 20。数据的实际宽度小于指定宽度时，默认在左侧补空格（右对齐）；大于指定宽度时，按实际宽度输出，不会截断。

n = 1234567
print("n(10):%10d." % n)
print("n(5):%5d." % n)

n(10):   1234567.
n(5):1234567.

对齐方式与标志

默认情况下输出是右对齐的。在最小宽度前加标志可以改变对齐和补位方式：

标志说明
-左对齐
+输出的数字总是带符号，正数带 +，负数带 -
0宽度不足时补 0，而不是补空格
  • 对整数指定左对齐时，在右边补 0 没有效果，因为会改变整数的值。
  • 对小数，三个标志可以同时存在。
  • 对字符串，只能使用 -：符号对字符串没有意义，补 0 会改变字符串的值。
n = 123456
print("n(09):%09d" % n)
print("n(+9):%+9d" % n)

f = 140.5
print("f(-+0):%-+010f" % f)

s = "Hello"
print("s(-10):%-10s." % s)

n(09):000123456
n(+9):  +123456
f(-+0):+140.500000
s(-10):Hello     .
  • %09d：最小宽度 9，左边补 0。
  • %+9d：最小宽度 9，带符号。
  • %-+010f：最小宽度 10，左对齐，带符号。这个例子的结果已有 11 个字符，超过了 10，所以没有补位。

指定小数精度

对浮点数还可以指定小数点后的位数。精度放在最小宽度之后，中间用点号 . 隔开，也可以不写宽度只写精度：

%m.nf
%.nf

m 是最小宽度，n 是输出精度，. 必须存在。对字符串，精度表示最多取前 n 个字符。

f = 3.141592653
print("%8.3f" % f)
print("%08.3f" % f)
print("%+08.3f" % f)
print("%.2f" % f, "%.3s" % "abcdef")

   3.142
0003.142
+003.142
3.14 abc
  • %8.3f：最小宽度 8，小数点后保留 3 位。
  • %08.3f：同上，左边补 0。
  • %+08.3f：同上，左边补 0，并带符号。

宽度和精度也可以用 * 从参数里取：

print("%*d|%-*d|" % (5, 42, 5, 42))

   42|42   |

按名称取值

在 % 后面用 (键名) 指定字典里的键，右边提供字典：

print("%(name)s今年%(age)d岁" % {"name": "小明", "age": 18})

小明今年18岁

字典本身的用法见 字典。

str.format()

字符串不能直接和数字用 + 拼接：

age = 63
try:
    txt = "My name is Bill, I am " + age
except TypeError as e:
    print(e)

can only concatenate str (not "int") to str

format() 方法接受传入的参数，格式化后放进字符串中占位符 {} 所在的位置，参数个数不限。

age = 63
txt = "My name is Bill, and I am {}"
print(txt.format(age))

quantity = 3
itemno = 567
price = 49.95
print("I want {} pieces of item {} for {} dollars.".format(quantity, itemno, price))

My name is Bill, and I am 63
I want 3 pieces of item 567 for 49.95 dollars.

位置与名称

  • 不写编号：按参数顺序依次填入。
  • 写索引 {0}、{1}：指定第几个参数，同一个参数可以重复使用。
  • 写名称 {name}：配合关键字参数。
quantity = 3
itemno = 567
price = 49.95
print("I want to pay {2} dollars for {0} pieces of item {1}.".format(quantity, itemno, price))

x = 1
y = 2
print("x = {}, y = {}".format(x, y))
print("x = {1}, y = {0}".format(x, y))
print("{0} {0} {1}".format("a", "b"))

num = 10
flag = True
print("整数：{intValue}, 布尔：{boolValue}".format(intValue=num, boolValue=flag))

I want to pay 49.95 dollars for 3 pieces of item 567.
x = 1, y = 2
x = 2, y = 1
a a b
整数：10, 布尔：True

占位符里还可以取元素和属性：

class P:
    x = 5

print("{0[k]} {1[1]} {2.x}".format({"k": 1}, [10, 20], P()))
print("{{}} {}".format(1))

1 20 5
{} 1

字面的大括号要写成 {{ 和 }}。

Warning

占位符数量多于参数会报 IndexError（按位置）或 KeyError（按名称）。

format_map()

format_map() 直接接受字典，适合用字典整体填充模板：

template = "姓名: {name}, 年龄: {age}, 城市: {city}"
data = {"name": "张三", "age": 25, "city": "北京"}
print(template.format_map(data))
print(template.format(**data))

姓名: 张三, 年龄: 25, 城市: 北京
姓名: 张三, 年龄: 25, 城市: 北京

format_map() 不会复制字典，配合带 __missing__ 的字典子类可以给缺失的键提供默认值，方法清单见 字符串方法。

f-string

在字符串前加 f（或 F），在 {} 里直接写变量或表达式。

  • {变量名=} 会在值前面打印 变量名=，调试时很方便。
  • {{ 和 }} 输出字面的大括号。
  • !r、!s、!a 分别调用 repr()、str()、ascii()。
name = "Irene"
age = 18
print(f"我的名字是{name}, 我的年龄是{age}")
print(f"我的个人信息：{name=}, {age=}")

pi = 3.14
print(f"圆周率{{pi}},{pi=}")
print(f"{age + 1} {name.upper()} {'x' * 3} {age > 10}")
print(f"{name!r} {name!s}")

n = 5
print(f"{n=}", f"{n*2=}", f"{n=:03d}")

我的名字是Irene, 我的年龄是18
我的个人信息：name='Irene', age=18
圆周率{pi},pi=3.14
19 IRENE xxx True
'Irene' Irene
n=5 n*2=10 n=005

Info

3.12 起，f-string 的表达式里可以重复使用外层的同类引号，也可以换行，例如 f"{"*" * 3}"。更早的版本要换用不同的引号：f"{'*' * 3}"。与 f-string 相关的 t-string 模板字符串见 Python 新版本特性。

格式控制

{} 里的冒号 : 后面可以写格式控制，对数字、字符串、日期做对齐、填充、精度等处理。str.format()、f-string 和内置函数 format(值, 格式) 的规则完全相同：

{变量:格式控制}               f"..." 与 "...".format(...) 通用
{位置编号:格式控制}
{变量别名:格式控制}

完整形式是 [[填充]对齐][符号][#][0][宽度][分组符][.精度][类型]，各部分都可以省略。

部分取值说明
填充任意一个字符写在对齐符前面，默认是空格
对齐< ^ >左对齐、居中、右对齐。数字默认右对齐，字符串默认左对齐
符号+ - 空格+ 正负数都显示符号，- 只显示负号（默认），空格表示正数前留一个空格
#加进制前缀 0b 0o 0x
0宽度不足时在数字左边补 0
宽度整数至少占几个字符，不足则补填充
分组符, 或 _每 3 位分隔一次（_ 用于二进制、十六进制时每 4 位）
精度.n浮点数小数点后保留 n 位；字符串最多取前 n 个字符
类型s d b o x X c e E f F g G %字符串、十进制、二进制、八进制、十六进制、字符、科学计数、浮点、自动选择、百分比

数字格式

print(f"{3.1415926:.2f} {3.1415926:+.2f} {-1:.2f} {2.71828:.0f}")
print(f"{5:0>2d} {5:x<4d} {10:x<4d}")
print(f"{1000000:,} {1000000:_} {0.25:.2%} {1000000000:.2e}")
print(f"[{13:>10d}] [{13:<10d}] [{13:^10d}]")
print("{:b} {:d} {:o} {:x} {:#x} {:#X}".format(11, 11, 11, 11, 11, 11))

3.14 +3.14 -1.00 3
05 5xxx 10xx
1,000,000 1_000_000 25.00% 1.00e+09
[        13] [13        ] [    13    ]
1011 11 13 b 0xb 0XB

对应图中的写法：{:.2f} 保留两位小数，{:0>2d} 左边补 0 到宽度 2，{:x<4d} 右边补 x 到宽度 4，{:,} 千分位，{:.2%} 百分比，{:.2e} 指数记法，{:>10d} 右对齐，{:<10d} 左对齐，{:^10d} 居中。

对齐与填充

print(f"[{'ab':*<8}] [{'ab':*^8}] [{'ab':*>8}] [{'ab':>8}]")
print(f"[{42:<8}] [{42:^8}] [{42:>8}] [{42:08}] [{-42:08}]")
print(f"[{5:+d}] [{-5:+d}] [{5: d}] [{3.14159:+.2f}]")
print(f"{'abcdef':.3}")

[ab******] [***ab***] [******ab] [      ab]
[42      ] [   42   ] [      42] [00000042] [-0000042]
[+5] [-5] [ 5] [+3.14]
abc

动态宽度与精度

宽度、精度本身也可以是变量，写在内层的 {} 里：

w = 10
pr = 3
print(f"[{3.14159:{w}.{pr}f}] [{'ab':{w}}]")
print("{:>{}}".format("x", 5))

[     3.142] [ab        ]
    x

format 与 f-string 对照示例

两种写法的格式控制完全一样，只是取值的方式不同：

name = "柴林燕"
age = 18
weight = 40.5

print("姓名：{:<10s}年龄：{:<10d}体重：{:<10.2f}|".format(name, age, weight))
print("姓名：{0:<10s}年龄：{1:<10d}体重：{2:<10.2f}|".format(name, age, weight))
print(f"姓名：{name:<10s}年龄：{age:<10d}体重：{weight:<10.2f}|")
print("姓名：{n}，年龄：{a}".format(n=name, a=age))

姓名：柴林燕       年龄：18        体重：40.50     |
姓名：柴林燕       年龄：18        体重：40.50     |
姓名：柴林燕       年龄：18        体重：40.50     |
姓名：柴林燕，年龄：18

Tip

宽度按字符个数计算，一个汉字算一个字符，但在多数终端里占两列，所以中英文混排时右边会错位。可以用全角空格 \u3000 作填充字符：f"{name:\u3000<6}"。

日期时间

日期时间对象可以直接用 strftime 指令作格式控制，指令见 datetime：

from datetime import datetime

dt = datetime(2026, 10, 12, 8, 5, 3)
print(f"{dt:%Y-%m-%d %H:%M:%S}")

2026-10-12 08:05:03

三种方式对照

同一段输出，三种写法：

name = "柴林燕"
age = 18
weight = 40.5

print("姓名：%s，年龄：%d，体重：%.1f" % (name, age, weight))
print("姓名：{}，年龄：{}，体重：{:.1f}".format(name, age, weight))
print(f"姓名：{name}，年龄：{age}，体重：{weight:.1f}")

姓名：柴林燕，年龄：18，体重：40.5
姓名：柴林燕，年龄：18，体重：40.5
姓名：柴林燕，年龄：18，体重：40.5
%str.format()f-string
位置/名称元组或 %(键)s{} {0} {name}直接写变量名
表达式先在外面算好先在外面算好可直接写在 {} 里
调试（name=）不支持不支持支持
模板复用容易容易不适合，f-string 在定义处立即求值
可读性占位符与值分离，参数多时难对应较好最好

新代码优先用 f-string；需要把模板存起来以后再填充（如从配置读取）时用 str.format() 或 format_map()；读到旧代码里的 % 要看得懂。
