PYTHON

Python 为字符串内置了一组方法。字符串不可变，所有方法都不会改动原字符串，而是返回新的结果（字符串、列表、布尔值或数字）。

s = "abc"
r = s.upper()
print(s, r, s is r)

abc ABC False

方法按用途分为下面几组。字符串的创建、索引、切片见 字符串，格式化见 字符串格式化，编码见 字符编码与 bytes。

查看方法：dir() 与 help()

dir(obj) 列出某个类、模块或对象里的全部内容，包括变量、方法、函数和类；obj 不写时列出当前范围内的名称。help(obj) 查看某个函数或模块的帮助文档；obj 不写时进入交互式帮助。掌握这两个函数，就能自己查阅 Python 里所有方法、函数、类的用法。

print("upper" in dir(str))
print("abc".upper.__doc__)

True
Return a copy of the string converted to uppercase.

help(str.upper)

Help on method_descriptor:

upper(self, /) unbound builtins.str method
    Return a copy of the string converted to uppercase.

去除空白与前后缀

方法说明
s.strip([x])去掉两端的空白字符或指定字符
s.lstrip([x])只去掉左边
s.rstrip([x])只去掉右边
s.removeprefix(p)去掉指定前缀（3.9+），没有匹配则原样返回
s.removesuffix(p)去掉指定后缀（3.9+），没有匹配则原样返回
a = " Hello, World! "
print(repr(a.strip()), repr(a.lstrip()), repr(a.rstrip()))
print("***hello***".strip("*"), "___hello___".lstrip("_"), "___hello___".rstrip("_"))

url = "https://www.example.com"
print(url.removeprefix("https://"), url.removeprefix("http://"))
filename = "document.pdf"
print(filename.removesuffix(".pdf"), filename.removesuffix(".txt"))

'Hello, World!' 'Hello, World! ' ' Hello, World!'
hello hello___ ___hello
www.example.com https://www.example.com
document document.pdf

Warning

strip() 系列的参数是一组字符，不是子串，遇到集合里的任何字符都会去掉。想去掉固定的前后缀，用 removeprefix() / removesuffix()：

print("test.txt".strip(".txt"))
print("test.txt".removesuffix(".txt"))

es
test

大小写转换

方法说明
s.upper()全部转大写
s.lower()全部转小写
s.swapcase()大小写互换
s.capitalize()第一个字符转大写，其余转小写
s.title()每个单词的首字母大写，其余小写
s.casefold()类似 lower()，但更彻底，适合不区分大小写地比较多语言文本
print("HELLO".lower(), "hello".upper(), "Hello World".swapcase())
print("hello WORLD".capitalize(), "hello world python".title())
print("straße".lower(), "straße".casefold(), "straße".upper())
print("straße".lower() == "STRASSE".lower(), "straße".casefold() == "STRASSE".casefold())
print("they're bill's".title())

hello HELLO hELLO wORLD
Hello world Hello World Python
straße strasse STRASSE
False True
They'Re Bill'S

title() 把撇号后面的字母也当作新单词的开头，处理 they're 这类缩写会出错。

查找与统计

方法说明
s.count(sub[, start[, end]])统计 sub 出现的次数，没有则返回 0
s.find(sub[, start[, end]])返回第一次出现的索引，没有返回 -1
s.rfind(sub[, start[, end]])同 find()，从右边开始查找
s.index(sub[, start[, end]])同 find()，找不到抛 ValueError
s.rindex(sub[, start[, end]])同 index()，从右边开始查找
s.startswith(prefix[, start[, end]])是否以 prefix 开头，返回 True 或 False
s.endswith(suffix[, start[, end]])是否以 suffix 结尾

参数含义：s 是原字符串，sub 是要检索的子串，start 是检索的起始位置（默认从头，包含该位置），end 是结束位置（默认到结尾，不包含）。字符串各字符的索引从 0 开始。

s = "c.biancheng.net"
print(s.count("."), s.count(".", 1), s.count(".", 2), s.count("ng"))
print(s.find("."), s.find(".", 2), s.find(".", 2, -4), s.rfind("."), s.find("zzz"))
print(s.index("."), s.rindex("."))
try:
    s.index("zzz")
except ValueError as e:
    print(e)

2 2 1 1
1 11 -1 11 -1
1 11
substring not found

s.find(".", 2, -4) 检索的范围是索引 2 到倒数第 4 个之间的 biancheng，里面没有 .，所以返回 -1。

startswith() 用来判断是否以指定内容开头，endswith() 判断结尾；前缀、后缀可以写成元组，满足其中任意一个就返回 True。

t = "http://c.biancheng.net/python/"
print(t.startswith("http"), t.startswith("https"), t.startswith("c.", 7))
print(t.endswith("/"), t.endswith("python/", 0), t.endswith("net", 0, 22))
print(t.startswith(("ftp", "http")))

True False True
True True True
True

Tip

只想知道子串在不在，直接用 in 运算符："net" in s。需要位置时才用 find()；find() 返回 -1 不抛异常，所以不要把返回值直接当布尔值用（索引 0 也是“假”）。

替换与翻译

replace(old, new[, count]) 把 old 替换成 new，指定 count 则最多替换这么多次。

print("Hello, World!".replace("World", "Kitty"), "aaaa".replace("a", "b", 2))

Hello, Kitty! bbaa

translate() 按翻译表一次性替换或删除多个字符，翻译表用 str.maketrans() 生成：

  • 一个参数：字典，键是字符（或其码点），值是替换内容或 None（删除）。
  • 两个参数：等长的字符串 str1、str2，str1 中的每个字符映射到 str2 相同位置的字符。
  • 三个参数：前两个同上，第三个字符串里的字符会被删除。
table = str.maketrans({"h": "H", "l": "L", "o": "O"})
print(table)
print("hello".translate(table))

table2 = str.maketrans("abc", "123")
print("bacadb".translate(table2))

table3 = str.maketrans("aeiou", "AEIOU", ",")
print("hello,world".translate(table3))

print("hello".translate({ord("l"): None}))

try:
    str.maketrans("ab", "1")
except ValueError as e:
    print(e)

{104: 'H', 108: 'L', 111: 'O'}
HeLLO
2131d2
hEllOwOrld
heo
the first two maketrans arguments must have equal length

拆分与连接

方法说明
s.split([sep[, maxsplit]])按分隔符切成列表（不含分隔符）
s.rsplit([sep[, maxsplit]])同 split()，从右边开始切
s.splitlines([keepends])按行切分
s.partition(sep)从左找第一个分隔符，切成三部分
s.rpartition(sep)从右找第一个分隔符，切成三部分
sep.join(iterable)用 sep 把可迭代对象里的字符串连成一个字符串

split() 与 rsplit()

  • sep：分隔符，可以含多个字符。不写或写 None 时，按空白字符（空格、\n、\t 等）切分，连续的空白当作一个分隔符，并且结果里没有空字符串。
  • maxsplit：最多切几次，结果最多有 maxsplit + 1 个子串；不写或为 -1 表示不限。
print("Hello, World!".split(","))
print("a b  c\n d\t e".split())
print("a,b,c,d".split(",", 2), "a,b,c,d".rsplit(",", 1), "a,,b".split(","))

['Hello', ' World!']
['a', 'b', 'c', 'd', 'e']
['a', 'b', 'c,d'] ['a,b,c', 'd'] ['a', '', 'b']

join()

join() 是合并字符串的主力：sep.join(iterable) 用 sep 作分隔符，把列表或元组里的多个字符串连起来。例如 c.biancheng.net 就是用 . 把 ['c', 'biancheng', 'net'] 连成的。

print(" ".join(["Hello", "World"]), "-".join(("a", "b", "c")), ".".join(["c", "biancheng", "net"]))
try:
    "-".join([1, 2])
except TypeError as e:
    print(e)

Hello World a-b-c c.biancheng.net
sequence item 0: expected str instance, int found

Tip

元素必须都是字符串，数字要先转换："-".join(map(str, [1, 2]))。循环里大量拼接字符串时，先把片段放进列表，最后调用一次 join()，比反复 += 更高效。

splitlines()、partition() 与 rpartition()

splitlines() 按 \n、\r、\r\n 等换行符切分，keepends=True 保留换行符。partition() 把字符串切成 (分隔符前, 分隔符, 分隔符后) 三部分，找不到分隔符时返回 (原字符串, '', '')；rpartition() 从右边找，找不到返回 ('', '', 原字符串)。

ml = """第一行
第二行
第三行"""
print(ml.splitlines())
print(ml.splitlines(True))
print("a\r\nb\rc\n".splitlines())

t = "hello-world-python"
print(t.partition("-"))
print(t.rpartition("-"))
print("helloworld".partition("-"), "helloworld".rpartition("-"))

['第一行', '第二行', '第三行']
['第一行\n', '第二行\n', '第三行']
['a', 'b', 'c']
('hello', '-', 'world-python')
('hello-world', '-', 'python')
('helloworld', '', '') ('', '', 'helloworld')

填充与对齐

方法说明
s.center(width[, fillchar])总宽度 width，文本居中，两侧用 fillchar 填充（默认空格）
s.ljust(width[, fillchar])左对齐，在右侧填充
s.rjust(width[, fillchar])右对齐，在左侧填充
s.zfill(width)右对齐，前面用 0 填充，符号位保持在最前
s.expandtabs([tabsize])把 \t 换成空格，默认每 8 列一个制表位

width 是包括 s 本身在内的总长度，小于或等于 len(s) 时原样返回。

text = "hello"
print(text.center(15, "*"))
print(text.ljust(15, "-"))
print(text.rjust(15, "."))
print(repr(text.center(15)))

S = "http://c.biancheng.net/python/"
addr = "http://c.biancheng.net"
print(S.ljust(35, "-"))
print(addr.ljust(35, "-"))

print("42".zfill(8), "-42".zfill(8), "+42".zfill(5), "abc".zfill(2))
print("a\tb".expandtabs(), "a\tb".expandtabs(4))

hello----------
..........hello

http://c.biancheng.net/python/-----
http://c.biancheng.net-------------
00000042 -0000042 +0042 abc
a       b a   b

判断类方法

这一组方法返回 True 或 False，空字符串一般返回 False（isascii() 例外）。

方法说明
s.isspace()非空且全是空白字符
s.isalpha()非空且全是字母（含汉字）
s.isalnum()非空且全是字母或数字
s.isdecimal()非空且全是十进制数字字符
s.isdigit()非空且全是数字（含上标数字 ² 等）
s.isnumeric()非空且全是数值字符（含罗马数字 Ⅻ、汉字数字 一二）
s.isascii()全是 ASCII 字符，空字符串也是
s.isupper()至少有一个区分大小写的字符，且这些字符都是大写
s.islower()至少有一个区分大小写的字符，且这些字符都是小写
s.istitle()非空且符合 title() 的格式
s.isidentifier()是否是有效的标识符（不排除关键字）
s.isprintable()是否全是可打印字符
print("  \t\n".isspace(), "".isspace(), " a ".isspace())
for s in ["abc", "abc中文", "abc123", "123", "", "²", "Ⅻ", "٣", "一二", "3.5"]:
    print(repr(s), s.isalpha(), s.isalnum(), s.isdecimal(), s.isdigit(), s.isnumeric())
print("abc".isascii(), "中".isascii(), "".isascii())
print("HELLO".isupper(), "Hello".isupper(), "123".isupper(), "hello".islower(), "hello1".islower(), "".islower())
print("Hello World".istitle(), "Hello world".istitle(), "".istitle())
print("name_1".isidentifier(), "1name".isidentifier(), "class".isidentifier(), "a-b".isidentifier())
print("abc".isprintable(), "a\nb".isprintable(), "".isprintable())

Note

想判断“是不是能转成数字”，这些方法都不可靠（"3.5" 全是 False，"²" 却是 True）。更稳妥的做法是直接 int() / float()，用 try-except 处理失败，见 try-except。

格式化与编码

  • s.format(*args, **kwargs) 和 s.format_map(mapping)：按模板填充，用法见 字符串格式化。format_map() 直接接受字典，不需要 ** 解包。
  • s.encode(encoding="utf-8", errors="strict")：按指定编码得到 bytes，见 字符编码。
template = "姓名: {name}, 年龄: {age}, 城市: {city}"
data = {"name": "张三", "age": 25, "city": "北京"}
print(template.format_map(data))
print("人生苦短".encode())
print("人生苦短".encode("gbk"))
