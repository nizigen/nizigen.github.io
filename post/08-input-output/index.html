PYTHON

input()

input() 是 Python 的内置函数，用于从控制台读取用户输入的内容，并存放到一个变量里。

变量 = input("提示信息：")
  • 变量是一个字符串类型的变量，input() 把读取到的内容放入其中。
  • 提示信息会显示在控制台上，告诉用户应该输入什么；如果不写，就不会有任何提示。
  • input() 函数总是以字符串的形式处理用户输入的内容，所以用户输入的内容可以包含任何字符。要进行计算，记得先转型。
username = input("请输入用户名：")
print("用户名是：", username)

age = int(input("请输入年龄："))
print("年龄是：", age)

请输入用户名：张三
用户名是： 张三
请输入年龄：18
年龄是： 18

输入的内容无法转换时会报错，例如在 int(input(...)) 处输入 abc：

ValueError: invalid literal for int() with base 10: 'abc'

Warning

input("...") 得到的永远是 str。"5" + "5" 是 "55" 而不是 10，所以做数值计算前要用 int() 或 float() 转换，见 类型转换。异常的处理方法见 try-except。

age = int(input(“请输入年龄：”).split(",")) 这个时候也会报错因为split()返回的shi’yi’ge

print()

print() 把内容打印到控制台，完整形式是：

print(value, ..., sep=' ', end='\n', file=sys.stdout, flush=False)
  • value：可以接受任意多个变量或值，多个内容之间用逗号隔开。
  • sep：指定输出多个内容时的分隔符，默认是一个空格。
  • end：指定输出结束后追加的内容，默认是 \n（换行）。
  • file：指定输出目标，默认是 sys.stdout，即屏幕。
  • flush：是否立即刷新缓冲区，默认 False。
print("hello world")   # 输出单个值

a = 1
b = 2
print("a = ", a, "，b = ", b)   # 输出多个参数值，用逗号分隔

# 指定参数的分隔符和结尾符
print("hello", "world", "python", sep="-", end=".")
print()   # 单独的 print() 只输出一个换行

# 用 % 格式化输出
print("a = %d, b = %d" % (a, b))

hello world
a =  1 ，b =  2
hello-world-python.
a = 1, b = 2

sep 与 end

sep 改变多个值之间的分隔符：

user_name = "Charlie"
user_age = 8
print("读者名：", user_name, "年龄：", user_age, sep='|')

读者名：|Charlie|年龄：|8

默认情况下 print() 输出之后总会换行，因为 end 的默认值是 "\n"。想让输出之后不换行，重设 end 即可：

print(40, '\t', end="")
print("接着输出")

40 	接着输出

Warning

参数名后的等号必须是半角字符。end="" 是正确写法，全角的 end＝"" 会报语法错误。

输出到文件

file 参数指定输出目标，完全可以通过改变它让 print() 输出到文件中：

with open("demo.txt", "w", encoding="utf-8") as f:   # 打开文件以便写入
    print('沧海月明珠有泪', file=f)
    print('蓝田日暖玉生烟', file=f)

demo.txt 中会有两行内容。with 语句会在结束时自动关闭文件，见 with 语句；文件读写的更多方法见 文件操作。

转义字符与格式化

输出中需要换行、制表符等特殊字符时使用转义字符，完整列表见 字符串字面量与转义字符。

% 占位符、str.format() 和 f-string 三种格式化输出方式，以及对齐、宽度、精度的控制，统一在 字符串格式化 里讲。
