数据类型概述

Python 是动态类型语言，变量不用显式声明类型，但变量引用的每个值都有明确的数据类型（见 变量）。

核心概念：一切皆对象。无论 int、float、bool 这样的基础类型，还是函数、类，在 Python 中都是对象。这与 Java 等语言不同，Python 是更彻底的面向对象语言。

按来源可以分为三层：

层次说明例子
内置类型不需要 import，也无需用 pip 等工具单独下载，可以直接使用原子类型：int、float、bool；容器类型：list、dict、str
标准库中的类型随 Python 安装，但需要 import定点小数 decimal.Decimal、datetime.datetime
扩展 / 自定义类型不属于 Python 核心。第三方库的类型要先 pip install；自定义类型用 class 定义numpy、pandas 的类型；自己写的 Person 类

内置数据类型按类别汇总如下，赋值时由解释器根据字面量自动确定类型：

类别类型示例
文本类型str"Hello World"
数值类型int、float、complex29、29.5、1j
序列类型list、tuple、range["apple", "banana"]、("apple", "banana")、range(6)
映射类型dict{"name": "Bill", "age": 63}
集合类型set、frozenset{"apple", "banana"}、frozenset({"apple"})
布尔类型boolTrue
二进制类型bytes、bytearray、memoryviewb"Hello"、bytearray(5)、memoryview(bytes(5))
空值NoneTypeNone

容器类型的对比见 容器类型概述。

类型判断：type 与 isinstance

有两种方式查看或判断类型：

  • type(变量或值)：直接返回类型，例如 type(c) 返回 <class 'int'>。
  • isinstance(变量或值, 类型)：判断是否为指定类型的实例，返回布尔值，类型可以写成元组表示"其中任意一种"。

两者的区别在于：type() 不会认为子类是一种父类类型，isinstance() 会。bool 是 int 的子类，所以：

a = 10
b = True
print(type(a), type(b), type(a) == type(b))
print(isinstance(a, bool), isinstance(a, int))
print(isinstance(b, bool), isinstance(b, int))
print(type(b) == int, isinstance(b, (int, str)))

<class 'int'> <class 'bool'> False
False True
True True
False True

Tip

判断类型时优先用 isinstance()，它能正确处理继承关系；只有需要精确判断"恰好是这个类型"时才用 type(x) is 类型。布尔值的更多细节见 布尔。

整数 int

Python 的整数取值范围是无限的，超过计算机自身的计算能力时，会自动转用高精度（大数）计算。整数类型是不可变的，不可变的类型才可以被共享。

Python 3.6+ 允许用下划线 _ 作为数字（整数和小数都可以）的分隔符，通常每隔三位加一个，下划线不影响数字本身的值。

a = 10
print(a)

a = 323_352_202_896_214_563_213_456_789
print(a)
print(2 ** 100)

10
323352202896214563213456789
1267650600228229401496703205376

小整数池

Python 把 [-5, 256] 范围内的整数预先创建好，维护在小整数对象池中，这些对象不会被垃圾回收。这个范围内的整数使用频率最高，复用同一个对象，可以省内存，避免频繁创建和销毁。所以不管在程序的什么位置，使用的位于这个范围内的整数都是同一个对象，例如 x = 1; y = 1 后 x is y 为 True。

Note

范围 [-5, 256] 是 CPython 的默认实现，其他 Python 实现（如 Jython、IronPython）的范围和细节可能不同。

超出这个范围的整数则要看情况：

  • 同一个 .py 文件内：解释器会对整个文件做优化，即使是大整数（如 300），两个变量赋相同的值，也可能指向同一个对象。
  • 交互式命令行或不同文件：代码是逐行或分文件加载的，超出小整数池范围的数，即使值相同也不会共享。

这种优化不是绝对的，取决于解释器和运行环境，所以判断两个整数是否相等永远用 ==，不要用 is。== 与 is 的区别见 == 与 is。

a = 10
b = 10
print(a == b)
print(id(a) == id(b))  # id() 返回对象在内存中的地址
print(a is b)          # is 判断是否为同一个对象

a = 300
b = 300
print(a == b)
print(id(a) == id(b))
print(a is b)

在 .py 脚本中运行，全部输出 True；在交互式命令行里逐行输入同样的代码，后两行输出 False。

# 运行时才创建的整数不会被编译器合并，可以稳定复现"不共享"
a = int("256")
b = int("256")
print(a is b)   # True，在小整数池范围内
a = int("257")
b = int("257")
print(a == b, a is b)

True
True False

浮点数 float 与 Decimal

float 对应其他语言的 double，可以用小数点或科学计数法书写。科学计数法 aEn 或 aen 等价于 a×10n，其中 E 或 e 是固定字符，用来分隔尾数和指数。

a = 3.1415926
print(a)

a = 3.1415926e7  # 科学计数法表示
print(a)

a = 3.14_15_926  # 使用下划线作为数字分隔符
print(a)

3.1415926
31415926.0
3.1415926

为什么 float 有误差

小数在内存中以二进制存储，小数点后的部分转成二进制时很可能是无限循环的数字，无论如何都无法精确表示，所以小数的计算结果一般是不精确的。float 的有效数字大约是 15 到 17 位，存储位数有限，超出的位数会被舍弃，舍弃的原则是"0 舍 1 入"。

a = 0.1
b = 0.2
c = 0.10000000000000001
print(a + b)    # 计算有误差
print(a == c)   # 近似就相等

0.30000000000000004
True

Warning

不要用 == 比较两个 float 的计算结果，0.1 + 0.2 == 0.3 是 False。可以用 math.isclose(0.1 + 0.2, 0.3) 判断是否足够接近，或用 round() 把结果取整到需要的位数。

Decimal

Decimal 由标准库 decimal 模块提供，用于解决 float 的精度问题，可以实现任意精度的十进制运算。

floatDecimal
内置还是标准库内置decimal 模块的 Decimal 类型
表示方式a = 0.1a = decimal.Decimal("0.1")，不加引号无法保证精度
精度范围整数加小数的总位数约 16~17 位可以表示任意精度，但计算时的精度位数由 decimal.getcontext().prec 决定，默认 28
from decimal import Decimal, getcontext

a = Decimal('0.1')
b = Decimal('0.2')
c = Decimal('0.10000000000000001')
print(a + b)    # 计算更精确
print(a == c)   # 一致才相等

print(1.0 / 3)
print(Decimal('1') / Decimal('3'))

getcontext().prec = 50   # 修改精度，默认是 28
print(Decimal('1') / Decimal('3'))

0.3
False
0.3333333333333333
0.3333333333333333333333333333
0.33333333333333333333333333333333333333333333333333
  • 创建 Decimal 时必须用字符串。如果写 Decimal(0.1)，数字会先按 float 处理，精度已经丢失，得到 0.1000000000000000055511151231257827021181583404541015625。
  • float 和 Decimal 不能直接混合运算，0.1 + Decimal('0.2') 会抛出 TypeError: unsupported operand type(s) for +: 'float' and 'decimal.Decimal'。Python 要求运算无二义性，运算前必须统一类型，要么都转 float，要么都转 Decimal。
  • 输出时显示的精度可以通过 round() 或格式化文本来控制，见 字符串格式化。

复数 complex

复数由实部（real）和虚部（imag）构成，在 Python 中虚部以 j 或 J 作为后缀，写成 a + bj。

z = 3 + 4j
print(z.real, z.imag, abs(z), type(z))
print((1 + 2j) * (3 - 1j))
print(complex(1, 2))

3.0 4.0 5.0 <class 'complex'>
(5+5j)
(1+2j)

abs(z) 返回复数的模。

类型转换

自动类型转换

自动类型转换遵循 Python 的"鸭子类型"哲学：只要操作有意义，Python 就会尝试自动处理类型兼容问题。

  • 两个布尔值做算术运算时，自动升级为 int。
  • 两个 int 做除法 / 时，自动升级为 float。
  • 两个不同的数值类型做混合运算时，小的类型自动升级为大的类型：bool < int < float < complex。
print(2 + 3.0)       # int 升级为 float
print(2 / 3)
print(True + True)   # bool 升级为 int
print(True + 1.5)

5.0
0.6666666666666666
2
2.5

Warning

Java 等语言里，任何类型与字符串用 + 连接都会隐式转成字符串，但 Python 不支持这种隐式转换。+ 在字符串之间表示拼接，且只支持字符串与字符串，其他类型要先用 str() 转换。

a = 2
b = "hello"
print(a + b)

TypeError: unsupported operand type(s) for +: 'int' and 'str'

强制类型转换

有时需要手动指定变量的类型，这称为 casting。Python 用类来定义数据类型，所以转换都是通过类型的构造函数完成的：

函数说明
int(x [, base])将 x 转换为整数；x 为字符串时可以用 base 指定进制
float(x)将 x 转换为浮点数
complex(real [, imag])创建一个实部为 real、虚部为 imag 的复数
str(x)将对象 x 转换为字符串
repr(x)将对象 x 转换为表达式字符串，会转义字符串中的特殊字符
eval(x)执行字符串表达式 x，并返回表达式的值
bin(x)将整数转换为二进制字符串
oct(x)将整数转换为八进制字符串
hex(x)将整数转换为十六进制字符串
ord(x)将一个字符转换为它的 Unicode 码点（整数）
chr(x)将一个整数转换为对应的 Unicode 字符
tuple(s)将序列 s 转换为元组
list(s)将序列 s 转换为列表
set(s)将 s 转换为可变集合
x = int(1)       # x 将是 1
y = int(2.5)     # y 将是 2
z = int("3")     # z 将是 3
print(x, y, z, int(-2.5))

print(float(1), float(2.5), float("3"), float("4.6"))
print(str("S2"), str(3), str(4.0))

1 2 3 -2
1.0 2.5 3.0 4.6
S2 3 4.0

要点：

  • int() 对浮点数是向零截断，不是四舍五入，也不是向下取整：int(2.9) 得 2，int(-2.9) 得 -2。四舍五入用 round()，它对 .5 采用"银行家舍入"（取偶数），round(2.5) 得 2，round(3.5) 得 4。
  • 字符串必须是合法的数字写法才能转换，int("3.5") 和 int("abc") 都会抛出 ValueError: invalid literal for int() with base 10；先转 float 再转 int 才可以：int(float("3.5"))。
  • int(x, base) 的字符串可以带进制，int("ff", 16) 得 255，int("101", 2) 得 5；base 传 0 时按字符串前缀判断，int("0b101", 0) 得 5。
  • bool 可以转换成数字：int(True) 得 1，float(True) 得 1.0。
  • 容器转换：list("abc") 得 ['a', 'b', 'c']，set([1, 1, 2]) 得 {1, 2}。
a = 123
b = "456"
print("a 数据类型为:", type(a))
print("类型转换前，b 数据类型为:", type(b))

c = int(b)  # 强制转换为整型
print("对 b 类型转换后，c 数据类型为:", type(c))

num_sum = a + c
print("a 与 c 相加结果为:", num_sum)
print("num_sum 数据类型为:", type(num_sum))

d = str(a)  # 强制转换为字符串
print("对 a 类型转换后，d 数据类型为:", type(d))
num_str = b + d
print("b 与 d 相加结果为:", num_str)
print("num_str 数据类型为:", type(num_str))

a 数据类型为: <class 'int'>
类型转换前，b 数据类型为: <class 'str'>
对 b 类型转换后，c 数据类型为: <class 'int'>
a 与 c 相加结果为: 579
num_sum 数据类型为: <class 'int'>
对 a 类型转换后，d 数据类型为: <class 'str'>
b 与 d 相加结果为: 456123
num_str 数据类型为: <class 'str'>

str 与 repr

str(x) 面向用户，得到可读的字符串；repr(x) 面向开发者，得到带引号、转义字符保留原样的表达式字符串，常用来调试。

print(str("a\nb"))
print(repr("a\nb"))

a
b
'a\nb'

eval

eval(x) 把字符串当作 Python 表达式执行并返回结果：

print(eval("1 + 2 * 3"))
print(eval("[1, 2] + [3]"))

7
[1, 2, 3]

Warning

不要对不可信的输入使用 eval()，它会执行字符串里的任意代码。只想把字符串还原成字面量（数字、列表、字典等）时，用 ast.literal_eval() 更安全：ast.literal_eval("[1, 2, {'a': 3}]")。

字符与编码值

ord() 和 chr() 在字符与 Unicode 码点之间转换，ord("a") 得 97，chr(97) 得 'a'，ord("中") 得 20013。字符编码的完整说明见 字符编码。

随机数不属于类型转换，生成随机数见 random。
