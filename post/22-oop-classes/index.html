面向过程把问题拆成一串步骤，面向对象把问题看成一组互相作用的对象。Python 两种范式都支持，程序变大之后，后者更容易扩展。这一篇讲类与对象本身：定义类、实例化、self、属性、三种方法、魔法方法，以及在运行时增删成员。封装、继承、多态见 封装、继承与多态。

面向过程与面向对象

面向过程面向对象
关注点解决问题的步骤涉及哪些对象、对象之间如何交互
组织单位函数类与对象
数据与操作分离，数据在函数之间传来传去绑在同一个类里
适合简单、一次性的任务需要扩展和复用的程序

做菜：两种写法

面向过程把做饭拆成五个函数，按顺序调用：

def buy():
    print("去超市购买食材...")

def wash():
    print("洗菜...")

def cut():
    print("切菜...")

def cook():
    print("开始烹饪...")

def serve():
    print("上菜啦！")

流程直白，但没有通用性：想做沙拉（不切不炒）、红烧肉（多一步烹饪）、紫菜汤（只煮），要么重写，要么往函数里加分支，函数越堆越乱。

面向对象先定义一个「菜」的模板，再让每种菜自己决定怎么做：

class Dish:
    def __init__(self, name):
        self.name = name

    def prepare(self):
        pass


class Salad(Dish):
    def prepare(self):
        print(f"为制作 {self.name} 购买食材。")
        print(f"清洗 {self.name} 的蔬菜。")
        print(f"切 {self.name} 的蔬菜。")
        print(f"将 {self.name} 装盘。")


class Stew(Dish):
    def prepare(self):
        print(f"为制作 {self.name} 购买食材。")
        print(f"清洗 {self.name} 的肉。")
        print(f"切 {self.name} 的肉。")
        print(f"烹饪 {self.name}。")
        print(f"将 {self.name} 装盘。")


class Soup(Dish):
    def prepare(self):
        print(f"为制作 {self.name} 购买食材。")
        print(f"煮 {self.name}。")


salad = Salad("蔬菜沙拉")
stew = Stew("红烧肉")
soup = Soup("紫菜鸡蛋汤")

salad.prepare()
print()
stew.prepare()
print()
soup.prepare()

数据（菜名）和操作（准备过程）放在同一个类里，这是封装；三种菜各自实现 prepare，同一个调用 菜.prepare() 得到不同结果，这是多态。以后再加菜品，只要写一个新子类，已有代码一行都不用动。

面向对象的历史

「对象」作为编程实体最早由 Simula 67 在 1960 年代引入——奥利-约翰·达尔和克利斯登·奈加特在挪威计算中心为模拟环境设计的语言，初衷是模拟船只，把不同类型的船只归纳成不同的类，每个对象基于它的类拥有自己的属性和行为。这是「把真实世界的对象映射为抽象对象」（模拟）的最早实践，也是「类」和「实例」两个概念的最早应用。

类与对象

类描述这一类对象共同的属性（有什么）和方法（能做什么），属性和方法统称为类的成员。

  • 类是对大量对象共性的抽象，是创建对象的模板；
  • 对象是类的具体实例（Instance），有自己的状态（属性）、行为（方法）和唯一标识（内存地址）。

定义类

class 类名:
    """类说明文档"""
    类体

类名用大驼峰命名法，规则见 标识符与命名。类体里可以放类属性（类变量）、方法、实例属性（实例变量）：

class Person:
    """人的类"""

    home = "earth"

    def __init__(self):
        self.age = 0

    def eat(self):
        print("eating...")

    def drink(self):
        print("drinking...")

构造方法 __init__()

__init__() 是实例初始化方法，习惯上叫构造方法，作用是在创建对象时初始化实例属性。用类名创建对象时 Python 自动调用它，并把新对象作为第一个参数（self）传进去。

  • self 是约定俗成的参数名，代表实例对象本身；
  • __init__() 不是必需的，没定义就走默认实现（什么都不做）；
  • __init__() 只能返回 None，返回其他值会抛 TypeError。
class Person:
    """人的类"""

    def __init__(self, name, age):
        """
        实例初始化方法
        :param name: 姓名
        :param age: 年龄
        """
        self.name = name
        self.age = age

    def print_info(self):
        """
        打印信息
        """
        print("姓名：", self.name)
        print("年龄：", self.age)


person = Person("张三", 18)
person.print_info()

姓名： 张三
年龄： 18

类属性与实例属性

类属性

在类中、方法外定义的属性叫类属性（类变量），值由类及其所有实例共享。

  • 推荐用 类名.类属性 访问和修改；
  • 也支持 实例.类属性 读取，但不推荐；
  • 实例.类属性 = 值 不是改类属性，而是给这个实例新增了一个同名实例属性。不要这样做会造成误解。
class Person:
    """人的类"""
    home = "earth"


print("Person.home = ", Person.home)

p1 = Person()
p2 = Person()
print("p1.home = ", p1.home)
print("p2.home = ", p2.home)

Person.home = "mars"
print("Person.home = ", Person.home)
print("p1.home = ", p1.home)
print("p2.home = ", p2.home)

p1.home = "venus"
print("Person.home = ", Person.home)
print("p1.home = ", p1.home)
print("p2.home = ", p2.home)
print("p1.__dict__ = ", p1.__dict__)

p2.home =  earth

Warning

执行 p1.home = "venus" 之后，Person.home 和 p2.home 都没变，而 p1.__dict__ 里多出了 'home'。属性查找先找实例再找类，从此 p1.home 读的是自己的实例属性，与类属性再无关系。要改类属性就写 Person.home = ...。

实例属性

在 __init__ 中通过 self.属性名 定义的属性叫实例属性（实例变量）。

  • 每个实例的实例属性互相独立；
  • 只能通过 实例.实例属性 访问和修改，不能用 类名.实例属性。
class Person:
    """人的类"""

    def __init__(self, name, age):
        self.name = name
        self.age = age


p1 = Person("张三", 18)
p2 = Person("李四", 20)
print("p1.name = ", p1.name, "p1.age = ", p1.age)
print("p2.name = ", p2.name, "p2.age = ", p2.age)

try:
    print(Person.name)
except AttributeError as e:
    print("Person.name ->", e)

方法

类里有三种方法：实例方法、类方法、静态方法。

实例方法

  • 第一个参数是 self，代表实例本身；
  • 类外可以用 实例.方法(参数) 或 类名.方法(实例, 参数) 调用；
  • 方法内部访问类属性/类方法推荐写 类名.成员，访问实例属性/实例方法写 self.成员。
class Person:
    """人的类"""

    home = "earth"

    def __init__(self, name):
        self.name = name

    @classmethod
    def print_home(cls):
        print("家庭住址：", cls.home)

    def eat(self):
        print(f"{self.name} is eating in {Person.home}")

    def print_info(self):
        self.eat()
        Person.print_home()

    def show_home(self):
        print(f"{self.home} VS {Person.home}")


p = Person("张三")

p.print_info()
Person.print_info(p)

print("=" * 20)

p.show_home()
p.home = "venus"
p.show_home()

类方法

  • 用 @classmethod 定义，第一个参数是 cls，代表类本身；
  • 可以访问本类的类属性和其他类方法；
  • 类外推荐 类名.类方法() 调用，也支持 实例.类方法()，但不推荐。
class Person:
    """人的类"""
    home = "earth"

    def __init__(self, name):
        self.name = name

    @classmethod
    def print_home(cls):
        print("家庭住址：", cls.home)


Person.print_home()
p1 = Person("张三")
p1.print_home()

家庭住址： earth
家庭住址： earth

静态方法

  • 用 @staticmethod 定义，不接收 self 或 cls；不加也不算错，但会触发警报。
  • 类和实例都能调用，本质是放在类里的工具函数，不碰类的内部数据；
  • 虽然能访问类属性、调用类方法，但一般不会这么做。
class Person:
    """人的类"""
    home = "earth"

    def __init__(self, name):
        self.name = name

    @classmethod
    def print_home(cls):
        print("家庭住址：", cls.home)

    def eat(self):
        print(f"{self.name} is eating in {Person.home}")

    @staticmethod
    def say(word):
        print("当前方法的参数word = ", word)
        print("当前类的属性home = ", Person.home)
        Person.print_home()


Person.say("hello")
p = Person("张三")
p.say("hi")

当前方法的参数word =  hello
当前类的属性home =  earth

当前方法的参数word =  hi
当前类的属性home =  earth
家庭住址： earth

在类外定义方法

类外定义的函数可以赋值给类中的变量，变量名就成了方法名。函数挂到类上仍是描述符，实例调用时照样绑定 self：

def speaking(self):
    print(f"{self.name} is speaking...")


class Person:
    """人的类"""

    def __init__(self, name):
        self.name = name

    speaking = speaking


class Parrot:
    """鹦鹉"""

    def __init__(self, name):
        self.name = name

    say = speaking


p = Person("张三")
p.speaking()

r = Parrot("发财")
r.say()

张三 is speaking...
发财 is speaking...

同一个函数挂到两个类上、方法名还可以不同，self 由调用者决定——这就是实例方法的绑定规则。

魔法方法

名字前后各有两个下划线的方法叫特殊方法（魔法方法），它们不手动调用，而是在特定操作发生时自动触发。下面这些之外还有 __len__、__iter__ 等，见 多态与鸭子类型。

方法触发时机
__new__(cls, *args)实例化时第一个被调用，负责创建并返回实例
__init__(self, ...)创建对象后初始化实例属性
__del__(self)对象被垃圾回收时（引用计数降到 0）
__getattribute__(self, name)访问任何属性之前
__setattr__(self, name, value)给任何属性赋值之前
__eq__、__ne__（与__eq__是一组只用重写一个即可）、__lt__、__le__、__gt__、__ge__==、!=、<、<=、>、>=
__str__(self)，默认返回类型以及地址str(对象)、print(对象)、format(对象)
__repr__(self)，默认返回类型以及地址repr(对象)、直接输出容器、调试工具

__new__ 必须调用 super().__new__(cls) 造出实例并返回；__getattribute__、__setattr__ 必须用 super() 转发，否则无限递归。

class Person:
    """演示常见特殊方法的类"""

    def __new__(cls, *args, **kwargs):
        print(f"1. 调用 __new__ 方法，创建 {cls.__name__} 的实例")
        return super().__new__(cls)

    def __init__(self, name, age):
        print("2. 调用 __init__ 方法，初始化对象")
        self.name = name
        self.age = age

    def __del__(self):
        print("7. 调用 __del__ 方法，销毁对象")

    def __str__(self):
        print("5. 调用 __str__ 方法")
        return f"姓名：{self.name}, 年龄：{self.age}"

    def __repr__(self):
        print("6. 调用 __repr__ 方法")
        return f"Person(name='{self.name}', age={self.age})"

    def __getattribute__(self, field_name):
        print(f"4. 访问属性 '{field_name}' (通过 __getattribute__ 拦截)")
        return super().__getattribute__(field_name)

    def __setattr__(self, field_name, field_value):
        print(f"3. 赋值属性 '{field_name}' = {field_value} (通过 __setattr__ 拦截)")
        if field_name == "age" and field_value <= 0:
            super().__setattr__(field_name, 0)
        else:
            super().__setattr__(field_name, field_value)

__eq__ 与比较族

默认继承自 object 的 __eq__ 比较的是内存地址（等价于 is，见 == 与 is），自定义类通常要重写它，让内容相同的两个对象判等——这也是 assert 对象A == 对象B 这类测试能成立的前提。

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __eq__(self, other):
        if not isinstance(other, Person):
            return NotImplemented
        return self.name == other.name and self.age == other.age

    def __str__(self):
        return f"Person(name='{self.name}', age={self.age})"

    def __repr__(self):
        return f"Person(name='{self.name}', age={self.age})"


p1 = Person("张三", 18)
p2 = Person("张三", 18)
p3 = Person("李四", 20)

print(str(p1))
print(repr(p1))
print(f"{p1!r}")
print(p1 == p2, p1 == p3, p1 != p3, p1 == "张三")
print([p1, p3])
print(p1)

        self.y = y

Warning

==定义了 __eq__ 的类，__hash__ 会被自动置为 None==，实例不再可哈希，放进 set 或当 dict 的键会抛 TypeError: unhashable type；确实需要哈希就自己再定义 __hash__。另外 __eq__ 遇到类型不匹配应返回 NotImplemented 而不是 False，把判断权交还给对方的 __eq__。

__str__ 与 __repr__

  • __str__ 面向用户，str(obj)、print(obj)、format(obj) 会调用它，重写时返回简洁友好的描述；
  • __repr__ 面向开发者，repr(obj)、直接输出列表等容器（用元素的 __repr__）、调试工具会调用它，理想结果是「能还原出该对象的表达式」；
  • 没有 __str__ 时 print(obj) 自动退到 __repr__，两个都没有就输出 <类名 object at 0x地址>。

上面的输出正好对应这两条：print([p1, p3]) 走元素的 __repr__，所以能看到 Person(name='张三', age=18)；Point 没重写，str() 和 repr() 都打印出了内存地址格式。

动态增删属性与方法

动态添加

类定义完成之后，仍然可以往类和实例上挂东西：

  • 动态添加类属性：类名.属性名 = 值；
  • 动态添加类方法：类外定义函数，加 @classmethod 且第一个参数为 cls，再 类名.新方法名 = 函数名；
  • 动态添加静态方法：类外定义函数，加 @staticmethod，再 类名.新方法名 = 函数名；
  • 动态添加实例属性：实例.属性名 = 值，只有这一个实例有；
  • 动态添加实例方法：实例.方法名 = types.MethodType(函数名, 实例)，只有这一个实例有。
import types


class Person:
    def __init__(self, name=None):
        self.name = name

    def eat(self):
        print(f"{self.name} is eating...")


Person.home = "earth"
print(f"Person.home = {Person.home}")

p1 = Person("张三")
p2 = Person("李四")
print(f"p1.name = {p1.name}, p1.home = {p1.home}")
print(f"p2.name = {p2.name}, p2.home = {p2.home}")


@classmethod
def come_from(cls):
    print(f"I come from {cls.home}")


@staticmethod
def print_info():
    print("I'm a Person")


Person.come_from = come_from
Person.print_info = print_info
Person.come_from()
Person.print_info()

p1.age = 18
print(f"p1.age = {p1.age}")
try:
    print(p2.age)
except AttributeError as e:
    print("p2.age ->", e)


def drink(self):
    print(f"{self.name} is drinking...")


p1.drink = drink
try:
    p1.drink()
except TypeError as e:
    print("p1.drink = drink 后 p1.drink() ->", e)

p1.drink = types.MethodType(drink, p1)
p1.drink()
try:
    p2.drink()
except AttributeError as e:
    print("p2.drink() ->", e)


def sleep(self):
    print(f"{self.name} is sleeping...")


Person.sleep = sleep
p1.sleep()
p2.sleep()

Tip

往实例上直接赋函数（p1.drink = drink）不会绑定 self：函数进了实例的 __dict__，不再是描述符，调用时不补第一个参数，所以报 missing 1 required positional argument: 'self'。要绑定就必须用 types.MethodType(函数, 实例)。 给类加实例方法则直接 类名.方法名 = 函数名，函数在类里还是描述符，每个实例调用时绑定自己的 self（输出最后两行）。反过来 类名.方法名 = types.MethodType(函数, 实例) 虽然能跑，但所有实例都会去读那一个实例的数据，是坑。

动态删除

del 类名.属性名        # 或 delattr(类名, "属性名")
del 实例对象名.属性名   # 或 delattr(实例对象名, "属性名")
del 类名.方法名

class Person:
    """人的类"""
    home = "earth"
    address = "地球"

    def __init__(self, name):
        self.name = name
        self.age = 18

    def eat(self):
        print(f"{self.name} is eating...")

    @classmethod
    def come_from(cls):
        print(f"I come from {cls.home}")


print("删除前类成员：", sorted(k for k in Person.__dict__ if not k.startswith("__")))

del Person.home
delattr(Person, "address")

p2 = Person("李四")

__slots__

__slots__ 是一个类属性，用来限定该类的实例能拥有哪些实例变量，顺带省掉每个实例的 __dict__：

  • 受它限制的「实例变量」既包括实例属性，也包括用 types.MethodType 挂上去的实例方法；
  • 对类属性、类方法、静态方法，以及通过类添加的实例方法没有限制；
  • 只对当前类生效，对子类无效。
import types


class Person:
    __slots__ = ("name", "age", "eat")

    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def show(cls):
        print("我是一个人")

    def drink(self):
        print("喝水")


Person.show()

Person.home = "地球"
print(Person.home)


@classmethod
def run(cls):
    print("跑")


Person.run = run
Person.run()

p = Person("张三", 23)
p.drink()

try:
    p.gender = "男"
except AttributeError as e:
    print("p.gender = '男' ->", e)


def eat(self):
    print("吃")


p.eat = types.MethodType(eat, p)
p.eat()


def sleep(self):
    print("睡觉")


Person.sleep = types.MethodType(sleep, p)
p.sleep()

try:
    p.sleep = types.MethodType(sleep, p)
except AttributeError as e:
    print("p.sleep = types.MethodType(sleep, p) ->", e)

__slots__ 里写了 eat，所以 p.eat = types.MethodType(eat, p) 合法；sleep 不在里面，实例上就加不上。Person.sleep = ... 是往类上加，不受 __slots__ 限制。
