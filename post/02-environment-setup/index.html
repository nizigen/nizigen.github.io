安装 Python

下载

官网：https://www.python.org/ ，在 Windows 下载页可以看到两类安装包。

类型适合谁内容
Installer（标准安装版）想在自己电脑上写代码、装库、做项目的 Python 程序员，一般都选它完整的标准库、解释器和 pip 等辅助工具，占用空间相对较大；下载 .exe，运行安装后在终端输入 python 或 pip 即可使用
Embeddable Package（可嵌入包）想把 Python 运行时"埋"进自己的程序里一起发布的开发者，例如让游戏引擎支持 Python 脚本只含最核心的解释器和必要组件，没有完整标准库，也没有 pip，通常只有几兆；应用内部调用 embed/python.exe 执行脚本

安装

  1. 双击下载好的文件，开始安装，建议以管理员身份运行。
  2. 选择自定义安装（Customize installation），并勾选 Add python.exe to PATH。
  3. 可选功能保持默认，直接 Next。
  4. 修改安装路径，其余保持默认，点击 Install。
  5. 安装结束时点击 Disable path length limit（取消系统对路径长度的限制，避免路径过长出错），再点 Close。

Note

“环境"指程序运行的操作系统环境，“变量"是用一个标识符代表的一个值。PATH 环境变量告诉 Windows 去哪些路径下找可执行程序（例如 python.exe），勾选后才能在任意目录直接输入 python。

验证

按 Win + R，输入 cmd 进入命令提示符，执行：

python --version

卸载

打开控制面板 → 程序 → 程序和功能，双击 Python 3.12.8（64-bit）即可卸载。

Warning

卸载过程中如果反复弹出 Could not set file security ... Error: 5 之类的确认框，持续按回车确认，直到不再弹出为止。

第一个 Python 程序

交互式命令行（REPL）

  1. Win + R，输入 cmd，进入命令提示符。
  2. 输入 python，进入交互模式。
  3. 输入 print("hello") 并回车，控制台打印 hello。

脚本模式

  1. 在 D 盘根目录新建文件，重命名为 Hello.py。
  2. 用记事本打开，写入 print("hello") 并保存。
  3. 在资源管理器地址栏输入 cmd 回车，会在当前路径打开命令提示符。
  4. 执行 python Hello.py。

两种模式对比

模式说明适合场景能写复杂代码吗
交互式 Shell（REPL）输入一行执行一行，立即看到结果快速测试、实验 API、计算、学习语法不适合：没有保存，难以修改和调试
脚本文件（.py）写完整程序，一次或反复执行复杂逻辑、函数、类、模块、大型项目完全支持

虚拟环境（venv）

把所有第三方库都装进系统 Python 里，不同项目的版本需求迟早会打架。虚拟环境是一个半隔离的 Python 环境，让包只为某个应用安装，而不是装到整个系统。

工具说明
venv标准库自带的创建虚拟环境的工具，Python 3.3 起内置；3.4 起会自动在新环境里安装 pip，3.5 起官方推荐用它
virtualenv第三方工具，是 venv 的前身和替代品，可在不含 venv 或无法自动装 pip 的旧版本（3.4 之前）上使用
pip首选的安装程序，3.4 起随 Python 安装包一起提供，详见 第三方库与打包

创建、激活和退出（Windows 命令提示符、PowerShell 与 Linux/macOS）：

# 在当前目录创建名为 .venv 的虚拟环境
python -m venv .venv

# Windows 命令提示符激活
.venv\Scripts\activate.bat
# Windows PowerShell 激活
.venv\Scripts\Activate.ps1
# Linux / macOS 激活
source .venv/bin/activate

# 退出虚拟环境
deactivate

创建出来的 .venv 目录里包含该环境专属的 python 与 pip，激活后在其中 pip install 的包不会影响系统 Python。

Warning

PowerShell 默认的执行策略可能禁止运行 Activate.ps1，遇到报错时可改用命令提示符激活，或调整当前用户的执行策略。

安装 PyCharm

什么是 IDE

集成开发环境（IDE，Integrated Development Environment）把代码编辑器、编译器或解释器接口、调试器和图形界面等工具集成在一起。用记事本加命令行也能写 Python，但繁琐、效率低；有了 IDE，很多工作交给它，可以专注于代码本身。本课程选用 PyCharm。

下载与安装

下载地址：https://www.jetbrains.com/pycharm/download

新版本不再区分专业版和社区版，统一为 Unified Product：试用 30 天，到期后仍可打开，只是限于基础功能。

安装步骤：双击安装包 → 下一步 → 修改安装目录 → 酌情勾选安装选项 → 安装 → 完成。

卸载

同样在"程序和功能"里选中 PyCharm 卸载，卸载程序会逐个删除安装目录下的文件。

PyCharm 基础设置

设置项说明
语言和地区可选
外观主题可选
文件编码设置 → 编辑器 → 文件编码，全局编码和项目编码都设为 UTF-8，创建 UTF-8 文件选"不含 BOM”，见下图
字体可选
代码自动补全设置为不区分大小写

创建 Python 工程

新建项目时，选择项目路径、填写项目名称、选择解释器类型并确认 Python 版本。

PyCharm 里最常见的三种环境类型：

特性Project venv（传统）Base conda（科学计算）uv（新一代极速工具）
核心机制用 Python 自带的 venv 模块创建隔离的虚拟环境，依赖用 pip 安装跨语言的包和环境管理系统，不仅管 Python，还能管 C++、R 等库（如 CUDA）用 Rust 编写，重写了依赖解析和安装逻辑，同时管理 Python 版本和项目依赖
速度较慢，复杂项目解析依赖可能要几十秒到几分钟较慢，求解器（Solver）速度是短板极快，比 pip 快 10~100 倍，几乎秒级完成
依赖锁定通常用 requirements.txt（不够严格）或 pip-tools用 environment.yml，跨平台兼容性有时出问题标准的 pyproject.toml 加自动生成的 uv.lock，严格且可复现
Python 版本管理不支持，要手动下载或用 pyenv支持，conda create -n py39 python=3.9支持，uv python install 3.12
适用场景标准项目，团队要求用最原生的官方工具数据科学、机器学习，依赖大量非 Python 底层库几乎所有新项目，尤其追求开发效率和环境稳定的团队

选择 Custom environment 后，下拉框里通常有两项：

  1. Existing environment：最常见。点 ... 浏览，选中电脑上已有的解释器，例如 D:\ProgramFiles\Python312\python.exe。勾选 Make available to all projects 后，该环境会进入 PyCharm 的全局解释器列表，方便其他项目复用，不勾选则只供当前项目使用。
  2. New environment using：借用这个界面手动调整路径，例如选 Virtualenv 创建，但手动指定环境文件夹位置（默认在项目根目录的 venv）。

在 PyCharm 中编写并运行代码

  1. 创建目录（便于管理）。
  2. 在目录中创建并命名 Python 文件。
  3. 编写代码并运行。

PyCharm 常用快捷键

快捷键作用
Alt + Enter万能修复：显示当前上下文下的建议操作，如自动导入包、修复语法错误、实现接口方法
Ctrl + D复制行：复制光标所在整行并粘贴到下一行
Ctrl + Y删除光标所在整行
Ctrl + /单行注释：注释或取消注释当前行
Shift + Enter在当前行下方开始新行，无论光标在行中哪个位置
Ctrl + Alt + Enter在当前行上方插入新行
Ctrl + Shift + Enter补全当前语句，并在下方开始新行
Ctrl + Shift + ↑/↓上下移动整行代码
Ctrl + Alt + L格式化代码，使其符合 PEP 8
Shift + F6重命名文件、类、变量或方法，所有引用处自动更新
Alt + J多行编辑：选中单词后每按一次选中下一个相同的单词，按 Esc 退出
Tab / Shift + Tab增加 / 减少缩进
