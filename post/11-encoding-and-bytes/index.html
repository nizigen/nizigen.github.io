PYTHON

计算机里只有 0 和 1，文本、数字、图片、视频最终都要变成二进制。文本里的每个字符要先对应一个数字，再把数字存成字节。字符串（str）面向字符，字节串（bytes）面向字节，两者靠“编码”和“解码”互相转换。字符串本身的用法见 字符串。

字符编码

字符集与编码方式

  • 字符集：规定每个字符对应哪个数字的表。最早的字符集是 ASCII，收录 0 到 127 共 128 个字符。
  • 编码方式：规定这些数字怎样存成字节。同一个字符集可以有不同的编码方式。
名称说明
ASCII128 个字符，每个字符 1 个字节，包含英文字母、数字、标点、控制字符
ISO-8859-1（Latin-1）256 个字符，每个字符 1 个字节，覆盖西欧文字
GB2312、GBK简体中文。ASCII 部分 1 个字节，汉字 2 个字节。GBK 是 GB2312 的扩展
Big5繁体中文
Shift-JIS日文
Unicode字符集，一张表收录世界上各国的常用文字
UTF-8、UTF-16、UTF-32Unicode 的编码方式。UTF-8 长度可变，占 1 到 4 个字节，英文 1 个字节，常用汉字 3 个字节

UTF-8、GBK、ISO-8859-1 都兼容 ASCII：纯 ASCII 文本用它们编码的结果是一样的。几个需要记住的 ASCII 值：

  • '0' 是 48，'A' 是 65，'a' 是 97。
  • 大写字母比对应小写字母小 32。

Tip

Python 3 的 str 就是 Unicode 字符串。str.encode() 不写编码时默认用 UTF-8。源文件和文本文件也建议统一用 UTF-8，规范见 编码规范。

ord() 和 chr()

  • ord(单个字符)：返回字符的 Unicode 码点。
  • chr(整数)：返回码点对应的字符，是 ord() 的逆操作。
letter = '0'
print(letter, "的 Unicode 编码值：", ord(letter))
print(ord("a"), ord("A"), ord("中"))

code = 100
print(code, "编码对应的字符：", chr(code))
print(chr(20013))

0 的 Unicode 编码值： 48
97 65 20013
100 编码对应的字符： d
中

encode() 和 decode()

  • 字符串.encode(编码方式)：把字符串编码成 bytes，相当于把“情报”按密码本加密成二进制。
  • bytes.decode(编码方式)：把 bytes 解码回字符串。

编码和解码必须使用同一种编码方式，否则会得到乱码或者报错。

string = "hello"
print(string, "的编码结果：", string.encode("UTF-8"))
for i in string.encode("UTF-8"):
    print(i, end=" ")
print()

string = "尚硅谷"
bytes_code = string.encode("UTF-8")
print(string, "的编码结果：", bytes_code)
result = bytes_code.decode("UTF-8")
print("解码结果：", result)

gbk_code = string.encode("gbk")
print("GBK：", gbk_code, len(gbk_code), "个字节")
print(gbk_code.decode("gbk"))

hello 的编码结果： b'hello'
104 101 108 108 111 
尚硅谷 的编码结果： b'\xe5\xb0\x9a\xe7\xa1\x85\xe8\xb0\xb7'
解码结果： 尚硅谷
GBK： b'\xc9\xd0\xb9\xe8\xb9\xc8' 6 个字节
尚硅谷

同一个汉字，不同编码占用的字节数不同：

print(len("a".encode("gbk")), len("汉".encode("gbk")), len("汉".encode()), len("😀".encode()))
print("尚".encode("utf-16"), "尚".encode("utf-16-le"), "a".encode("utf-32-le"))

1 2 3 4
b'\xff\xfe\x1a\\' b'\x1a\\' b'a\x00\x00\x00'

utf-16 会在开头加字节序标记（BOM，本例的 \xff\xfe），指定 utf-16-le 或 utf-16-be 则不加。

乱码与 errors 参数

用错误的编码方式处理数据，常见的后果是乱码，或者直接抛出 UnicodeDecodeError / UnicodeEncodeError：

gbk_code = "尚硅谷".encode("gbk")
try:
    gbk_code.decode("utf-8")
except UnicodeDecodeError as e:
    print(type(e).__name__, e)

try:
    "😀".encode("gbk")
except UnicodeEncodeError as e:
    print(type(e).__name__, e)

UnicodeDecodeError 'utf-8' codec can't decode byte 0xc9 in position 0: invalid continuation byte
UnicodeEncodeError 'gbk' codec can't encode character '\U0001f600' in position 0: illegal multibyte sequence

encode()、decode() 以及 文件操作 里 open() 的 errors 参数决定遇到无法处理的字符时怎么办：

errors 取值行为
strict默认值，抛出 UnicodeError
ignore跳过无法处理的内容
replace编码时用 ? 代替，解码时用 Unicode 替换字符 U+FFFD 代替
backslashreplace用反斜杠转义序列代替
xmlcharrefreplace编码时用 XML 字符引用代替
print("中a".encode("ascii", errors="ignore"))
print("中a".encode("ascii", errors="replace"))
print("中a".encode("ascii", errors="backslashreplace"))
print("中a".encode("ascii", errors="xmlcharrefreplace"))

broken = b"a\xe5\xb0b"
print(repr(broken.decode("utf-8", errors="ignore")))
print(ascii(broken.decode("utf-8", errors="replace")))

b'a'
b'?a'
b'\\u4e2da'
b'&#20013;a'
'ab'
'a\ufffdb'

Warning

ignore 和 replace 会悄悄丢失信息，只适合“尽量读出来”的场合。数据要保真时保持默认的 strict，并在读写时明确写 encoding="utf-8"。

bytes

字节串（bytes）和字符串的对比：

strbytes
组成若干字符若干字节，每个字节是 0 到 255 的整数
操作单位字符字节
可变性不可变不可变
字面量"abc"b"abc"，只能含 ASCII 字符
方法大部分方法相同，如 upper()、replace()、startswith()同左，但参数也必须是 bytes

bytes 只负责以二进制形式存储数据，这些数据代表字符串、数字、图片还是音频，完全由程序的解析方式决定。选对字符集，字节串就能恢复成字符串。

创建 bytes

b1 = bytes()
b2 = b''
b3 = b'http://c.biancheng.net/python/'
b4 = bytes('C语言中文网8岁了', encoding='UTF-8')
b5 = "C语言中文网8岁了".encode('UTF-8')
print(b1, b2, b3, b4, b5, b4 == b5, sep="\n")

b''
b''
b'http://c.biancheng.net/python/'
b'C\xe8\xaf\xad\xe8\xa8\x80\xe4\xb8\xad\xe6\x96\x87\xe7\xbd\x918\xe5\xb2\x81\xe4\xba\x86'
b'C\xe8\xaf\xad\xe8\xa8\x80\xe4\xb8\xad\xe6\x96\x87\xe7\xbd\x918\xe5\xb2\x81\xe4\xba\x86'
True
  • b 前缀：字符串内容都是 ASCII 字符时，直接加 b。含中文会报 SyntaxError: bytes can only contain ASCII literal characters。
  • bytes(字符串, encoding=...)：构造方法，不指定字符集时必须给出 encoding（只传字符串会 TypeError）。
  • 字符串.encode(...)：最常用，不指定字符集默认 UTF-8。
  • 其他构造：bytes(3) 得到 3 个 \x00，bytes([65, 66, 67]) 由整数列表创建，bytes.fromhex("e5b09a") 由十六进制文本创建。
print(bytes(3), bytes([65, 66, 67]), bytes.fromhex("e5b09a"))
print(b"abc".hex(), "尚".encode().hex())

b'\x00\x00\x00' b'ABC' b'\xe5\xb0\x9a'
616263 e5b09a

操作 bytes

索引得到的是整数，切片得到的是 bytes，不能修改元素：

x = b"hello"
print(x[0], x[1:3], len(x), list(x[:3]))
print(x + b" world", x.upper(), x.replace(b"l", b"L"), x.startswith(b"he"), b"l" in x)

try:
    x[0] = 72
except TypeError as e:
    print(e)

try:
    b"a" + "b"
except TypeError as e:
    print(e)

104 b'el' 5 [104, 101, 108]
b'hello world' b'HELLO' b'heLLo' True True
'bytes' object does not support item assignment
can't concat str to bytes

bytes 和 str 不能直接混用，需要先 decode() 或 encode()。

bytearray

需要修改字节时用可变的 bytearray：

ba = bytearray(b"hello")
ba[0] = 72
ba.append(33)
print(ba, bytes(ba))

bytearray(b'Hello!') b'Hello!'

与文件操作的关系

以二进制模式（"rb"、"wb"）打开文件读到的就是 bytes，图片、音频、压缩包都这样处理；文本模式读到的是 str，背后会按 encoding 解码，见 文件操作。
