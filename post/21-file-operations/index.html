PYTHON

程序运行时的数据都在内存里，进程一结束就没了。要把数据留下来就得写进磁盘文件，这个过程叫持久化。Python 用内置的 open() 打开文件拿到文件对象，再用这个对象读写；文件和目录的增删改查交给标准库 os、os.path 和 shutil。

文件的概念

文件是存储在磁盘上的数据集合，可以装文本、图像、音频、视频或程序代码。文件系统靠路径 + 文件名定位文件。

文件名通常由名称和扩展名组成，扩展名表示类型（.txt 文本、.jpg 图像、.py 代码）。路径分两种：

绝对路径相对路径
Windows从盘符开始，如 D:\atguigu\hello.py不以盘符开头，如 ./atguigu/hello.py、..\..\hello.py
Linux / macOS从根目录 / 开始，如 /users/hello.py不从 / 开头，如 ./atguigu/hello.py、../../hello.py
  • ./ 表示当前目录，../ 表示上级目录。
  • 相对路径依赖当前工作目录，同一个相对路径在不同目录下运行会指向不同文件，所以脚本里操作文件时常用绝对路径，或者用 os.path.join(os.path.dirname(__file__), ...) 拼出稳定路径。

按内容分两类：

  • 纯文本文件：有统一的字符编码，可以看成一串存在磁盘上的长字符串。一般以字节为单位或一行为单位。常见编码有 ASCII、ISO-8859-1/Latin1、GB2312、GBK、UTF-8、UTF-16，编码细节见 字符编码与 bytes。.py,.html,.txt,.js .md .css
  • 二进制文件：没有字符编码和解码的概念，直接由 0 和 1 组成，比如图片、视频、压缩包、可执行文件。只能以字节为单位。

打开与关闭

无论是读写IO操作最初都是打开文件，最后一步都是关闭文件。不close虽然不报错，但是底层C的内存释放不能自动进行。日积月累内存占用会很严重。

open() 的参数

open(file, mode="r", buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)
参数说明默认
file要打开的文件路径（位置 + 文件名），也可以传整数型文件描述符必选
mode操作类型（读 / 写 / 追加）和打开格式（文本 / 二进制）"r"
buffering读写缓冲策略。磁盘读写远慢于内存，缓冲就是先在内存里攒数据、到阈值再一次性写盘，减少 IO 次数-1
encoding文本模式下按什么编码把字节解码成字符串、把字符串编码成字节。仅文本模式有效，二进制模式指定它会直接报错。默认 None，表示用"系统默认编码"，取值由系统区域设置和 UTF-8 模式共同决定None
errors文本模式下编码或解码出错时的处理方式，只能文本模式用None
newline仅文本模式有效，控制读取时怎么解析换行符、写入时怎么替换换行符，用来抹平 Windows \r\n、Linux/macOS \n、旧 Mac \r 的差异None
closefd调用 close() 时是否连底层文件描述符一起关闭True
opener自定义打开函数，替换内置逻辑，用于权限校验、加密文件等高级场景，新手用不到None

不传 encoding 时到底用什么编码，看这三个值就清楚了：

import locale
import sys

print("系统区域编码 locale.getencoding():", locale.getencoding())
print("open() 默认编码 locale.getpreferredencoding(False):", locale.getpreferredencoding(False))
print("UTF-8 模式是否开启（sys.flags.utf8_mode）:", sys.flags.utf8_mode)

系统区域编码 locale.getencoding(): cp936
open() 默认编码 locale.getpreferredencoding(False): utf-8
UTF-8 模式是否开启（sys.flags.utf8_mode）: 1

Warning

别依赖 open() 的默认编码。同一份代码换台机器可能从 UTF-8 变成 GBK，读同样的文件就抛 UnicodeDecodeError。读写文本文件一律显式写 encoding="utf-8"（或数据本身的编码）；设置环境变量 PYTHONUTF8=1 或加 -X utf8 会打开 UTF-8 模式，把它变成默认值。编码本身的原理见 字符编码与 bytes。

mode 的组合规则

mode 由基础操作符、格式标识和扩展标识组合而成：

类型符号含义注意
基础操作r只读（默认）文件不存在报错，指针在开头
w只写文件不存在则创建，存在则清空原内容
a追加写文件不存在则创建，指针在末尾，不覆盖原内容
格式标识t文本模式（默认，可省略）读写的是字符串，可指定 encoding
b二进制模式读写的是 bytes，用于图片、视频、压缩包等；禁止指定 encoding
扩展标识+读写模式，叠加在基础符后面r+ 读 + 写不清空，w+ 写 + 读清空，a+ 追加 + 读
x独占创建写文件不存在则创建，存在则报错（避免覆盖）

buffering 的取值

buffering 只支持整数，一般不用改，用默认的 -1：

取值含义
-1默认缓冲：文本模式用系统默认缓冲区大小（一般 4096 / 8192 字节），二进制模式用固定块缓冲
0无缓冲，数据直接读写磁盘。仅二进制模式有效，文本模式设 0 会报错
1行缓冲，仅文本模式有效，遇到 \n 就刷盘
>=2固定大小缓冲，单位字节，如 buffering=4096 表示 4K 缓冲

errors 的取值

取值含义
strict严格模式，也是默认值：遇到编码错误直接抛 UnicodeError，程序终止
ignore忽略模式：跳过出错的字节继续处理，可能导致字符丢失
replace替换模式：把出错的字节替换为 �（U+FFFD 替换字符），不终止程序，避免乱码
backslashreplace转义替换：把出错的内容替换成 Python 转义序列，如 \xff
surrogateescape代理转义：把无法解码的字节存成代理字符，写回时能还原，适合读取系统文件

造一个含非法字节的文件看实际效果：

with open("bad.txt", "wb") as f:
    f.write("你好".encode("utf-8") + b"\xff\xfe" + "abc".encode("utf-8"))

for mode in ("strict", "ignore", "replace", "backslashreplace", "surrogateescape"):
    try:
        with open("bad.txt", encoding="utf-8", errors=mode) as f:
            s = f.read()
        print(f"errors={mode:<18} -> {s!r}")
    except Exception as e:
        print(f"errors={mode:<18} -> {type(e).__name__}: {e}")

errors=strict             -> UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 6: invalid start byte
errors=ignore             -> '你好abc'
errors=replace            -> '你好��abc'
errors=backslashreplace   -> '你好\\xff\\xfeabc'
errors=surrogateescape    -> '你好\udcff\udcfeabc'

二进制模式不允许指定 encoding，文本模式也不允许 buffering=0：

try:
    open("bad.txt", "rb", encoding="utf-8")
except ValueError as e:
    print("ValueError:", e)

try:
    open("bad.txt", "r", buffering=0)
except ValueError as e:
    print("ValueError:", e)

ValueError: binary mode doesn't take an encoding argument
ValueError: can't have unbuffered text I/O

newline 的作用

with open("crlf.txt", "wb") as f:
    f.write(b"a\r\nb\r\nc")

with open("crlf.txt", "r", encoding="utf-8") as f:
    print("newline=None（默认，通用换行）:", repr(f.read()))
with open("crlf.txt", "r", encoding="utf-8", newline="") as f:
    print('newline=""（不做转换）:', repr(f.read()))
with open("crlf.txt", "r", encoding="utf-8", newline="\n") as f:
    print('newline="\\n"（只按 \\n 断行，保留 \\r）:', repr(f.read()))

newline=None（默认，通用换行）: 'a\nb\nc'
newline=""（不做转换）: 'a\r\nb\r\nc'
newline="\n"（只按 \n 断行，保留 \r）: 'a\r\nb\r\nc'

读的时候默认把 \r\n、\r 都翻译成 \n；写的时候默认把 \n 翻译成当前系统的换行符。要原样保留文件里的字节，用 newline=""。

返回的文件对象类型

open() 返回一个文件对象，具体类型由模式决定：

f = open("bad.txt", "r", encoding="utf-8")
print(type(f))
f.close()

f = open("bad.txt", "rb")
print(type(f))
f.close()

f = open("out.bin", "wb")
print(type(f))
f.close()

f = open("out.bin", "rb+")
print(type(f))
f.close()

<class '_io.TextIOWrapper'>
<class '_io.BufferedReader'>
<class '_io.BufferedWriter'>
<class '_io.BufferedRandom'>
  • 文本模式（r、w、rt、wt 等）返回 TextIOWrapper；
  • 二进制只读返回 BufferedReader，二进制写入或追加返回 BufferedWriter，二进制读写返回 BufferedRandom。

读写接口因此不同：文本模式读写 str，二进制模式读写 bytes。

close() 关闭文件

f.close()

文件用完必须关闭：释放系统资源（文件描述符是有限的），并把缓冲区里没落盘的数据刷出去。异常发生时如果没关闭，数据可能丢失。

Tip

手工 close() 容易漏，尤其是中途抛异常时。用 with 语句让 Python 自动关闭，写法与原理见 24.错误与异常。本文示例里只有演示手动关闭的段落才用 close()，其余地方用 with。

读写文件

下面所有示例都在一个临时目录里演练：documents、copy 这类目录不是自动生成的，需要自己建好（见下图），示例里的 documents/test.txt、documents/哈希表.mp4 都是示例路径，换成自己的真实文件才跑得起来。可在系统临时目录里照做一遍，跑完把目录删掉。

覆盖写

w 模式打开时，文件不存在就创建，存在就把原内容清空再写：

def write_one():
    fw = open("./documents/test.txt", "w", encoding="utf-8")
    fw.write("hello world\n")
    fw.write("hello atguigu\n")
    fw.close()

def write_two():
    fw = open("./documents/test.txt", "w", encoding="utf-8")#第二次调用直接清空
    fw.write("你好，世界\n")
    fw.write("你好，尚硅谷\n")
    fw.close()

write_one()
print(open("./documents/test.txt", encoding="utf-8").read())
print("--- 再调用 write_two() ---")
write_two()
print(open("./documents/test.txt", encoding="utf-8").read())

复制文件的五种方式

复制方式操作对象复制内容复制权限复制元数据（时间）大文件友好开关文件推荐场景
read() + write()字符串 / 字节是否否否，整个读进内存手动小文本文件
shutil.copyfileobj文件对象是否否是，流式手动大文件、网络流、自定义
shutil.copyfile路径是否否是自动只复制内容，最快
shutil.copy路径是是否是自动复制内容 + 权限
shutil.copy2路径是是是是自动内容 + 权限 + 元数据，最接近系统复制

shutil 是 Python 内置的文件操作工具库：

  • shutil.copy(src, dst)：复制内容和文件权限。
  • shutil.copy2(src, dst)：复制内容 + 权限 + 元数据（创建时间、修改时间等），更推荐。
  • copyfileobj 专门复制已打开的文件对象，按 shutil.COPY_BUFSIZE 分块（Python 3.13 在 Windows 上是 1048576 字节，即 1MB），也可以手动给更大的分块。copy / copy2 底层就是靠它复制内容的。
  • dst 传目录时，copy / copy2 会用源文件名放进该目录。
import shutil

# documents/哈希表.mp4 是示例路径，换成自己的文件
shutil.copy2(r"documents/哈希表.mp4", r"copy/哈希表_copy.mp4")

import shutil

# 传的是文件对象，用 with 保证两个文件都关掉
with open("documents/哈希表.mp4", "rb") as fr, open("copy/哈希表_copy.mp4", "wb") as fw:
    shutil.copyfileobj(fr, fw, 1024 * 1024)

用一个真实文件对比五者的差别（源文件只读时权限差异才看得出来）：

import os
import shutil
import stat
import hashlib

os.makedirs("documents", exist_ok=True)
os.makedirs("copy", exist_ok=True)

src = "documents/video_demo.bin"
with open(src, "wb") as f:
    f.write(b"\x00\x01\x02" * 5000)
OLD_TIME = 1600000000  # 2020-09-13
os.utime(src, (OLD_TIME, OLD_TIME))


def digest(path):
    with open(path, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()[:12]


def report(name, dst):
    same_content = digest(src) == digest(dst)
    same_mode = stat.S_IMODE(os.stat(src).st_mode) == stat.S_IMODE(os.stat(dst).st_mode)
    same_mtime = int(os.stat(src).st_mtime) == int(os.stat(dst).st_mtime)
    print(f"{name:<22} 内容一致={same_content}  权限一致={same_mode}  修改时间一致={same_mtime}")


with open(src, "rb") as fr, open("copy/v1.bin", "wb") as fw:
    fw.write(fr.read())
report("read()+write()", "copy/v1.bin")

with open(src, "rb") as fr, open("copy/v2.bin", "wb") as fw:
    shutil.copyfileobj(fr, fw, 1024 * 1024)
report("shutil.copyfileobj", "copy/v2.bin")

shutil.copyfile(src, "copy/v3.bin")
report("shutil.copyfile", "copy/v3.bin")

shutil.copy(src, "copy/v4.bin")
report("shutil.copy", "copy/v4.bin")

shutil.copy2(src, "copy/v5.bin")
report("shutil.copy2", "copy/v5.bin")

read()+write()         内容一致=True  权限一致=True  修改时间一致=False
shutil.copyfileobj     内容一致=True  权限一致=True  修改时间一致=False
shutil.copyfile        内容一致=True  权限一致=True  修改时间一致=False
shutil.copy            内容一致=True  权限一致=True  修改时间一致=False
shutil.copy2           内容一致=True  权限一致=True  修改时间一致=True

只读文件上 copyfile 与 copy 的区别：

os.makedirs("perm", exist_ok=True)
src = "perm/src.txt"
with open(src, "w", encoding="utf-8") as f:
    f.write("read only test")
os.chmod(src, stat.S_IREAD)   # 源文件设为只读
print("源文件只读：", not os.access(src, os.W_OK), oct(stat.S_IMODE(os.stat(src).st_mode)))

for name, fn in (("copyfile", shutil.copyfile), ("copy", shutil.copy), ("copy2", shutil.copy2)):
    dst = f"perm/{name}.txt"
    if os.path.exists(dst):
        os.chmod(dst, stat.S_IWRITE)
        os.remove(dst)
    fn(src, dst)
    print(f"{name:<10} 目标只读={not os.access(dst, os.W_OK)}  模式={oct(stat.S_IMODE(os.stat(dst).st_mode))}")
    os.chmod(dst, stat.S_IWRITE)

os.chmod(src, stat.S_IWRITE)

源文件只读： True 0o444
copyfile   目标只读=False  模式=0o666
copy       目标只读=True  模式=0o444
copy2      目标只读=True  模式=0o444

Windows 上权限只有"只读"这一位，所以 copyfile 和 copy 在普通文件上看不出差别；Linux/macOS 上 copy 会连读写执行位一起复制。shutil.COPY_BUFSIZE 是默认分块大小，本机是 1048576 字节。

大文件分块复制与进度

一次 read() 整个大文件会占满内存，正确做法是分块读写，顺便算出进度：

import os

os.makedirs("documents", exist_ok=True)
os.makedirs("copy", exist_ok=True)

# 造一个 5MB 的测试文件；真实场景里换成 documents/哈希表.mp4 这类大文件
with open("documents/big_demo.bin", "wb") as f:
    f.write(os.urandom(5 * 1024 * 1024))


def copy_big_file(src, dst):
    fr = open(src, "rb")
    fw = open(dst, "wb")
    # 获取源文件大小（字节）
    file_size = os.path.getsize(src)
    copied_size = 0  # 已复制大小
    while True:
        data = fr.read(1024 * 1024)
        if not data:
            break
        fw.write(data)
        # 更新已复制大小并打印进度
        copied_size += len(data)
        progress = (copied_size / file_size) * 100
        print(f"\r复制进度：{progress:.2f}% ({copied_size}/{file_size} 字节)", end="")
    print("\n复制完成！")
    fr.close()
    fw.close()


copy_big_file("documents/big_demo.bin", "copy/big_copy.bin")

复制进度：20.00% (1048576/5242880 字节)
复制进度：40.00% (2097152/5242880 字节)
复制进度：60.00% (3145728/5242880 字节)
复制进度：80.00% (4194304/5242880 字节)
复制进度：100.00% (5242880/5242880 字节)
复制完成！

\r 让光标回到行首，下一次打印覆盖上一次，所以终端里只看到一行不断刷新；把输出重定向到文件时会看到每一步。实测 5MB 文件的分块进度是 20%、40%、60%、80%、100%。

Warning

源文件大小为 0 时 (copied_size / file_size) 会 ZeroDivisionError，先判空再算进度。另外文本模式不能按字节随意切分（多字节字符会被切断），大文件一律用 "rb" / "wb"。

获取文件或目录属性

os.path 提供了一批查询函数，不改动文件本身：

  • os.path.abspath() 把相对路径补成绝对路径，依赖当前工作目录。

创建文件

open("documents/test1.txt", "w").close()

open(..., "w") 打开就会创建空文件，不写内容时记得 close()。也可以用 pathlib.Path("a.txt").touch()。

重命名与移动文件

  • os.rename(old, new)：同磁盘重命名。
  • shutil.move(src, dst)：移动，也可以顺带重命名。
os.rename("documents/test1.txt", "documents/test2.txt")
print("test1 存在：", os.path.exists("documents/test1.txt"),
      " test2 存在：", os.path.exists("documents/test2.txt"))

    os.rename("documents/test2.txt", "documents/test3.txt")
except FileExistsError as e:
    print("FileExistsError:", e)

shutil.move("documents/test3.txt", "backup/")

shutil.move通用移动 / 重命名同磁盘直接重命名，跨磁盘先复制再删原文件支持支持

Warning

os.rename 在 Windows 上目标已存在会直接 FileExistsError；shutil.move 目标已存在时会直接覆盖，覆盖后原文件无法恢复。移动前先 os.path.exists(dst) 检查。

os.remove() / os.unlink() 删除的文件不进回收站，不可恢复。删除前务必确认路径，尤其是用变量拼出来的路径；要先备份就复制一份再删。上面的示例只在系统临时目录里操作，跑完把临时目录清掉。

统计目录大小

目录本身没有"大小"，要把里面所有文件加起来。递归写法：

def get_dir_size(path):
    if not os.path.exists(path):
        return 0
    if os.path.isfile(path):
        return os.path.getsize(path)
    total_size = 0
    for inner_sub in os.listdir(path):
        sub_path = os.path.join(path, inner_sub)
        total_size += get_dir_size(sub_path)
    return total_size


print("documents目录大小：", get_dir_size('./documents'), "字节")

documents目录大小： 5257929 字节

os.walk 加生成器的写法更短：

total_size = sum(os.path.getsize(os.path.join(r, f))
                 for r, _, fs in os.walk(r"documents") for f in fs
                 if not os.path.islink(os.path.join(r, f)))
print(f"os.walk 目录总大小：{total_size} 字节")

os.walk 目录总大小：5257929 字节

两种写法都把软链接排除了，避免重复计算和死循环。
