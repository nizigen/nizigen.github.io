学习路径建议

  • 第一次学：01 → 37 顺序读完即可，编号就是依赖顺序。语法部分（0309）可以边读边在 REPL 里敲，容器与字符串部分（1019）最好配着练习过一遍方法。
  • 写代码时回查：07（运算符）、12（格式化）、13（字符串方法）、16（列表）、18（字典）用得最频繁。
  • 卡在某个概念上：作用域问题看 29，可变/不可变和拷贝问题看 30，装饰器看不懂先补 29 的闭包再看 32。
  • 只看新东西：直接读 37，其余笔记都已按 3.13 的语法写。
