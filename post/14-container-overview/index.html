PYTHON

容器（container）是能够存放多个元素的对象。Python 内置的容器有列表 list、元组 tuple、字符串 str、集合 set、字典 dict，另外 collections 模块还提供了 deque、defaultdict、Counter 等更专用的容器，见 collections。

容器可以按两个维度分类：

  • 能不能改（可变 / 不可变）：改的是元素本身，比如 list[0] = 10。
  • 有没有顺序（有序 / 无序）：有序的能用索引和切片访问。

字典 3.7 以后按插入顺序输出，但仍然没有索引，取值只能靠键，所以归为无序。集合同理，虽然 CPython 里整数集合看着像排好序的，但那是实现细节，不能依赖。

可变与不可变

可变容器可以直接增删改元素，对象本身不变；不可变容器改不了元素，想做"修改"只能生成一个新对象并让变量重新指向它。

# ---------- 可变容器 ----------
listDemo = [1, 2, 3, 4, 5, 3, 4, 5]
print(f"列表{listDemo}")
listDemo.append(6)
print(f"追加元素6之后列表{listDemo}")
listDemo[0] = 10
print(f"修改[0]为10之后列表{listDemo}")

setDemo = {1, 2, 3, 4, 5, 3, 4, 5}
print(f"集合{setDemo}")
setDemo.add(6)
print(f"添加元素6之后集合{setDemo}")
setDemo.remove(3)
print(f"删除元素3之后集合{setDemo}")

dictDemo = {"name": "Irene", "age": 18}
print(f"字典{dictDemo}")
dictDemo["sex"] = "female"
print(f"修改字典之后字典{dictDemo}")
del dictDemo["age"]
print(f"删除字典的age之后字典{dictDemo}")

bytearrayDemo = bytearray(b'hello')
print(f"字节数组{bytearrayDemo}")
bytearrayDemo[0] = 65
print(f"修改字节数组[0]元素之后字节数组{bytearrayDemo}")

# ---------- 不可变容器 ----------
rangeDemo = range(1, 10)
print(f"{rangeDemo}遍历", end="：")
for i in rangeDemo:
    print(i, end=" ")
print()

stringDemo = "Irene"
print(f"字符串{stringDemo}")
stringDemo = stringDemo.replace('r', 'a')  # 原对象不可修改，返回新对象
print(f"替换字符串r为a之后字符串{stringDemo}")

tupleDemo = (1, 2, 3, 4, 5)
print(f"元组{tupleDemo}")

bytesDemo = bytesDemo.replace(b'r', b'a')
print(f"替换字节串r为a之后字节串{bytesDemo}")

frozensetDemo = frozenset([1, 2, 3, 4, 5])
print(f"冻结集合{frozensetDemo}")

Warning

range、str、tuple、bytes、frozenset 都既不支持 seq[0] = x，也不提供 append、add、remove 这类方法。给元组的元素重新赋值报 TypeError: 'tuple' object does not support item assignment，给冻结集合调 add() 报 AttributeError。

但"变量重新赋值"从来不等于"修改原对象"：stringDemo = stringDemo.replace(...) 是让变量指向了一个新的 str 对象。详见 元组与列表的区别。

容器通用操作

不管哪种容器，下面这些操作都能用（sum() 例外，要求元素是数值）：

操作写法说明
成员判断x in container、x not in container字典判断的是键，不是值
长度len(container)元素个数
遍历for x in container:逐个取出元素
最大值max(container)需要元素之间能比较
最小值min(container)同上
求和sum(container)元素必须能相加，通常用于数值
nums = [1, 2, 3, 4, 5]
print("nums：", nums)
print("4在列表中吗？", 4 in nums)
print("列表的长度是：", len(nums))
for num in nums:
    print(num, end=" ")
print()
print("列表中的最大值是：", max(nums))
print("列表中的最小值是：", min(nums))
print("元素的累加和是：", sum(nums))

words = ["hello", "world", "python", "atguigu"]
print("words：", words)
print("hello在列表中吗？", "hello" in words)
print("列表的长度是：", len(words))
print("列表中的最大值是：", max(words))
print("列表中的最小值是：", min(words))

max()、min() 对字符串容器也能用，比较的是字典序（按字符编码逐个比）。sum() 只做加法，元素是字符串就会报错：

try:
    print(sum(["hello", "world"]))
except TypeError as e:
    print(type(e).__name__, e)

TypeError unsupported operand type(s) for +: 'int' and 'str'

Tip

索引、切片、index()、count()、+、* 只有序列才有（列表、元组、字符串、range），见 序列；集合和字典各自的专有操作见 集合、字典。
