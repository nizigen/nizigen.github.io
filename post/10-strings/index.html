PYTHON

字符串（str）是由字符组成的、有序且不可变的序列。Python 没有单独的字符类型，单个字符就是长度为 1 的字符串。

  • 通用的序列操作见 序列，容器共有的操作见 容器通用操作。
  • 字符与字节的转换见 字符编码与 bytes，格式化输出见 字符串格式化，字符串自带的方法见 字符串方法。

字符串字面量与转义字符

引号

用单引号、双引号、三个单引号或三个双引号包裹的文本都是字符串对象，类型都是 str。

  • 单行文本：单引号 'hello' 或双引号 "world"，内容只能在一行内。
  • 多行文本：三个单引号 '''...''' 或三个双引号 """..."""，内容可以跨行，换行符、制表符等都原样保留（所见即所得）。
a = 'hello'
b = "hello"
c = """
    hello
    world
"""
d = '''
    hello
    python
'''
print(type(a), type(b), type(c), type(d))

<class 'str'> <class 'str'> <class 'str'> <class 'str'>

三引号字符串同样可以赋值给变量，常用来存放多行文本或文档注释。

Warning

三引号结尾必须正好是三个引号。结尾写成四个引号（""""）会多出一个引号，开启一个没有结束的新字符串，报 SyntaxError: unterminated string literal。

字符串内容里本身有引号时：

  • 外层用单引号，内部可以直接写双引号，反之亦然，不需要转义。
  • 内外引号相同，才需要对内部的引号转义。
print('他说："你好"')
print("It's fine")
print('It\'s fine', "他说：\"你好\"")

他说："你好"
It's fine
It's fine 他说："你好"

转义字符

转义字符用来表示无法直接输入或有特殊含义的字符，如换行、制表符、反斜杠本身。它以反斜杠 \ 开头。

转义字符说明
\写在行尾，表示续行符
\\反斜杠本身
\'单引号
\"双引号
\n换行，光标移到下一行开头
\r回车，光标移到本行开头
\t水平制表符（Tab）
\b退格，光标左移一列
\a响铃，多数电脑已经没有蜂鸣器，不一定有声音
\v、\f垂直制表符、换页符，很少使用
\ooo1 到 3 位八进制编码值，例如 \101 是 A
\xhh恰好 2 位十六进制编码值，例如 \x41 是 A
\uXXXX、\UXXXXXXXX4 位、8 位十六进制的 Unicode 码点
\N{名称}按 Unicode 名称，例如 \N{SNOWMAN}
print("C:\\new\\table")
print("\141\x61", "\u2603", "\N{SNOWMAN}")

C:\new\table
aa ☃ ☃

用编码值来间接表示字符，这种方式叫转义。\xhh 后面必须跟满两位十六进制数，"\x4" 会报 SyntaxError。ASCII 一共 128 个字符，三位八进制 \ooo 和 \xhh 都能覆盖全部。

Note

旧笔记写“\0 后最多两位数字，八进制不能表示全部 ASCII 字符”。实际上八进制转义最多可写 3 位，"\177" 就是 ASCII 的最后一个字符（码点 127）。

制表位、退格和回车

  • \t 把光标移到下一个制表位，用来简单对齐。制表位的宽度由终端决定，常见为 8 列。
  • \b 删除前一个字符的显示：print("hello\bworld") 在终端里看到的是 hellworld。
  • \r 回到行首并覆盖：print("lily\rhi") 在终端里看到的是 hily，hi 覆盖了 li，ly 保留。不同终端的覆盖方式略有差异，核心都是回到行首。

制表位按 8 列计算时，hello 和 chai 后面的 \t 都会跳到第 9 列，所以三列文字上下对齐：

print("hello\tworld\tai".expandtabs(8))
print("chai\tlin\tyan".expandtabs(8))

hello   world   ai
chai    lin     yan

expandtabs() 的说明见 字符串方法。要对齐大段文本，更推荐用格式化，见 格式控制。

续行符

行尾的 \ 把一行过长的代码在视觉上拆成多行，逻辑上仍是一行。在三引号字符串里，行尾的 \ 表示这个换行不算进字符串。

total = 1 + \
    2
print(total)

text = """
    hello\
    world
"""
print(repr(text))

3
'\n    hello    world\n'

Warning

续行符后面不能有任何字符，包括空格，否则报 SyntaxError: unexpected character after line continuation character。括号内的换行不需要续行符，优先用括号。

原始字符串

在字符串前加 r 或 R，所有内容按字面意思处理，反斜杠不再是转义字符。常用于 Windows 路径和正则表达式（见 正则表达式）。

print(r"hello\nworld")
print(r"C:\new\table", len(r"\n"))
print(R"a\b")

hello\nworld
C:\new\table 2
a\b

Warning

原始字符串不能以奇数个反斜杠结尾。r"abc\" 里的 \" 仍会被当作“引号被转义”，导致字符串没有结束，报 SyntaxError。结尾需要反斜杠时可以写 r"abc\\"（得到两个反斜杠），或者用普通字符串拼接。

字符串驻留

为了节省内存，CPython 对一部分字符串使用驻留（intern）机制：内容相同的字符串只保留一份，多个变量共享同一个对象，靠引用计数决定是否销毁。这和 小整数池 的思路类似。

一般的规律是：只由字母、数字、下划线组成的字符串（长得像标识符）会被自动驻留；含空格等其他字符的字符串，在不同的语句里分别创建时通常不共享。下面用 exec 模拟每条语句单独编译：

import sys
ns = {}
for src in ['a = "hello"', 'b = "hello"', 'c = "hello world"', 'd = "hello world"']:
    exec(src, ns)
print(ns["a"] is ns["b"], ns["c"] is ns["d"])

x = "".join(["hel", "lo"])
print(x == ns["a"], x is ns["a"], sys.intern(x) is ns["a"])

True False
True False True
  • 运行时拼接出来的字符串（如 join 的结果）不会自动驻留，sys.intern() 可以手动驻留。
  • 同一个 .py 文件里的相同字面量，编译器可能合并成同一个常量，所以在脚本里对 "hello world" 用 is 也可能得到 True。

Warning

驻留是 CPython 的实现细节，不同版本、不同运行方式的结果可能不同。比较字符串内容永远用 ==，不要用 is，两者的区别见 == 与 is。

索引与切片

字符串是有序序列，每个字符有一个索引（下标）：从左往右从 0 开始递增，从右往左从 -1 开始递减。

  • 方括号访问单个字符：s[0]。
  • 切片 s[start:end:step] 取一段，包含 start，不包含 end，缺省规则见 切片。
  • 越界的单个索引会抛 IndexError，越界的切片不会报错。
s = "helloworld"
print(s[0], s[-1])
print(s[1:5], s[2:-3], s[::2], s[::-1])
print(s.index("l"), s.count("l"), max(s), min(s))
print("l" in s, "xyz" not in s, len(s))
for i, ch in enumerate("hey"):
    print(i, ch)

h d
ello llowo hlool dlrowolleh
2 3 w d
True True 10
0 h
1 e
2 y

字符串不可变，不能通过索引修改字符，也没有 append、insert、remove、sort、reverse 这类修改原对象的方法。想“修改”就得生成新字符串：

s = "Hello, World!"
try:
    s[0] = "h"
except TypeError as err:
    print(err)

t = "h" + s[1:]
print(t, s)

'str' object does not support item assignment
hello, World! Hello, World!

输出里只有新字符串 t 的首字母变成了小写 h，原字符串 s 保持不变。

字符串长度与字节数

len() 返回字符的个数。需要字节数时，先用 encode() 编码再取长度，字节数取决于编码方式：数字、英文字母、小数点、下划线和空格各占 1 个字节，汉字在 GBK 中占 2 个字节，在 UTF-8 中一般占 3 个字节。

str1 = "人生苦短，我用Python"
print(len(str1))
print(len(str1.encode()))
print(len(str1.encode("gbk")))

13
27
20

UTF-8 下 7 个汉字（含中文逗号）占 21 个字节，加上 6 个英文字母，共 27 个字节。编码的细节见 字符编码。

拼接与重复

  • 相邻的字符串字面量会自动拼接："str1" "str2"。
  • + 拼接两个字符串变量，* 重复字符串。
  • Python 不允许字符串和数字直接用 + 拼接，要先转成字符串（str()、repr()），或者用 格式化。
  • 字符串不可变，+= 每次都会创建新对象；循环里大量拼接时，先放进列表再用 "".join() 一次合并，见 字符串方法 里的 join()。
print("Python" "3", "ab" + "cd", "-" * 10)

age = 63
try:
    txt = "I am " + age
except TypeError as err:
    print(err)
print("I am " + str(age))
print(f"I am {age}")

Python3 abcd ----------
can only concatenate str (not "int") to str
I am 63
I am 63

str() 与 repr()

str() 和 repr() 都能把对象转成字符串，区别在于面向的读者：

函数面向特点
str(obj)人适合阅读的形式，str("chiyuki") 得到 chiyuki
repr(obj)解释器、开发者尽量写成合法的 Python 表达式，repr("chiyuki") 得到 'chiyuki'（带引号），适合开发和调试
v = "chiyuki"
print(str(v), repr(v))
print(str("a'b"), repr("a'b"))
print(str([1, "a"]), repr([1, "a"]))
print(eval(repr(v)) == v)

try:
    eval(repr(object()))
except SyntaxError:
    print("SyntaxError")

chiyuki 'chiyuki'
a'b "a'b"
[1, 'a'] [1, 'a']
True
SyntaxError

repr() 的结果对大多数内置类型可以用 eval() 还原；对象没有对应的字面量时，repr() 返回 <...> 形式，eval() 就会 SyntaxError。

Warning

eval() 会执行任意表达式，不要对不可信的输入使用。

格式化字符串里 %r、%s、!r、!s 分别对应这两个函数，见 字符串格式化。
